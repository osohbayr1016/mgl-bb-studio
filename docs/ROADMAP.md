# Дараагийн ажлууд

Эрэмбэ = ББ инженерийн өдөр тутмын ажилд хамгийн их цаг хэмнэх дарааллаар. 1 ба 2-ыг эхэлж хийхийг зөвлөсөн.

## 1. Хамрах хүрээ + бодит төсөл дээрх туршилт

- Хучилтын 1:20 огтлол (байрлалыг инженер сонгоно) ба хучилтын түүвэр (7- цуврал).
- Суурь (тууз, ганцаарчилсан, хавтан), шат, рамын огтлол.
- Давхцлын «800» хэмжээс (дэлгээс дээрх нийлүүлгийн урт).
- Хэт өндөр түүврийг хуудсанд хувааж багтаах (Б-5).
- Ханын төлөвлөгөөний огтлолд MRA шошго давхцахгүй байрлуулах.
- Нэг хоёр бодит төсөл дээр инженертэй хамт: юу засагдсаныг «Асуудал – Шийдэл»-ээр цуглуулж стандартыг сайжруулах.
- Олон гишүүнийг багцаар үүсгэх хурд (одоо гишүүн бүр тусдаа гүйлгээ).

## 2. Загвар өөрчлөгдөхөд зураг шинэчлэгдэх

Арматур / гишүүн засагдсан бол тэр гишүүний харагдац, хэмжээс, шошго, түүврийг дахин үүсгэх (өөрийн тэмдэглэгээг `BbAnnoStore`-оор солих,
гараар тавьсныг хөндөхгүй). «Аль зураг хуучирсан бэ» жагсаалт.

## 3. Чанарын шалгалт (QA)

Хуудас гаргахаас өмнө: шошгогүй арматур, хэмжээсгүй огтлол, хоосон түүвэр, давхардсан марк, хуудаснаас гарсан харагдац, стандартаас зөрсөн
масштаб / загвар → «Асуудал – Шийдэл»-д.

## 4. Ярианы команд (MGL AI)

«ДН-1-ийн зургийг гарга», «6-р хуудсыг дахин тэмдэглэ» гэх мэт — MGL AI-аас энэ нэмэлтийн командыг дуудах.

## 5. Арматурын тооцоо (LIRA) + нормын шалгалт

LIRA-гийн үр дүнгээс шаардлагатай арматурыг уншиж загварын арматуртай тулгах, нормын хамгийн бага хэмжээ (хамгаалах үе, алхам).

## 6. Төслийн түвшин

Зургийн жагсаалт, дугаарлалт, засварын (revision) бүртгэл, PDF багц, ERP-ийн явцад холбох.

## 7. Арматур үүсгэх (дамнуруу → багана)

CADS Rebar Extensions / Naviate Rebar-ийн хэв маягаар, БНбД 52-01 / СП 52-101-ээр. Эх өгөгдөл — LIRA-ийн As санал болгоно, инженер цонхонд
засна; бүх загварыг төрөл / маркаар нь нэг дор.

- [x] Норм `Core/BbRebarCode.cs` (анкерлах, холбоос, хамгаалах үе, цэвэр зай, хомутын алхам / диаметр, As → n×d) + тест.
- [x] Олон алгаслын дамнурууны төлөвлөгөө `Core/BbBeamRebarPlan.cs` (үндсэн + нэмэлт дээд / доод, давхцуулах, 90° хөл, консол,
  хомут 1 / 3 бүс / «4*200+5*300») + тест.
- [x] Компанийн горим `BbBeamPreset.Company(b)` — ЖИШЭЭ-1-ийн 80 дамнуруунаас хэмжсэн (тулгуурын дээд + голын Ø12, 4 салаа хомут @100/@200,
  хажуугийн Ø12 + C-хомут, туслах дамнуруунд 3@50 + 4Ø16 муруй) + тест.
- [x] Revit: тулгуур / туслах дамнуруу таних, `Rebar.CreateFromCurves` (R24–R27), `MGL-BB-GEN` тэмдэгтэй — дахин үүсгэхэд солино
  (ЖИШЭЭ-1 ДН-2: 6 алгасал, 149 элемент, алдаагүй).
- [x] «Арматур» самбар: «Дамнурууны арматур» (марк бүрийн мөр, LIRA CSV санал), «Баганын арматур».
- [x] Багана: nb×nh, механик залгаас / давхцал, тахир, L, доош суулгах, хосын дотоод хомут — ЖИШЭЭ-1-ээс.
- [x] Хувьсах огтлолтой гинж — огтлол бүрийн хэсэг, тулгуургүй залгаасанд анкерлана.
- [x] Цонхонд урьдчилсан зураг; хомутын хэлбэр сонгох; хажуугийн арматур; алгасал бүрийн хүснэгт; элементийн cover; норм зөрчихгүй.
- [x] Арын горим (явцын цонх, «Зогсоох», гишүүн бүр өөрийн Ctrl+Z) — ЖИШЭЭ-1 (2027) дээр 60 гинж 4376 элемент, 0 алдаа.
- [x] Загвараас хэв маяг сурах (дамнуруу + багана), ЖИШЭЭ 3-аас: хомутын бүс, туслахын хомут, C-хомут, хазайсан дамнуруу, нимгэн хана.
- [x] «Энгийн каркас» ЖИШЭЭ-4-өөс (хомут ¼l @100 / @200, тулгуурын дээд ⅓l + голын Ø12 500 давхцал); хэв маяг хоёр горимд ч.
- [x] Хамгаалах үе: хомут / баганын хомутын баруун, доод тал (Revit-ийн 51 хэлбэрийн d/2 шилжилт), хөлтэй арматур, үзүүр + d/2, bbox-ийн өндөр.
- [x] Өндөр нь өөр, өргөн ижил хэсгүүдийн дээд арматур тасралтгүй (ЖИШЭЭ-4 ДН-4).
- [ ] Баганын ажлын арматурын байрлал — ЖИШЭЭ-4-ийн 47 м нэг элемент баганад Revit 16–19 мм шилжүүлдэг, засвар тогтворжихгүй.
- [ ] ЖИШЭЭ-4: захын алгаслын нягт бүс заримдаа инженерийн шийдлээр (ДН-9 12 / 11), ТДН-5 жигд @150; доод арматур баганад +100 гарах дүрэм.
- [ ] Туслах дамнурууны (ТДН) хомутын дүрэм — жишээнд тогтмол бус (нэг талдаа ⅔ нягт гэх мэт), одоо үндсэн дамнуруутай адил.
- [ ] LIRA-аас шууд унших (CSV-гүй); нэрлэсэн preset файл (төсөл хооронд).
- [ ] Суурийн гарц арматур, налуу дамнуруу / багана, T / L огтлол.
- [ ] Revit дээрх 4 мм-ийн зөрүү (доод арматур / хомутын доод тал — Revit-ийн хамгаалах үеийн хязгаарлалт) шалгах.
