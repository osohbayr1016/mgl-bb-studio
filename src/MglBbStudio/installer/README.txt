MGL ББ Студи — бүтээцийн ажлын зургийн ТУСДАА Revit нэмэлт (Revit 2024–2027)
=============================================================================

Энэ нэмэлт нь үндсэн «MGL» plugin-аас ТУСДАА: өөрийн «MGL ББ» таб, өөрийн манифест (MglBbStudio.addin),
өөрийн хавтас (%LOCALAPPDATA%\MGL\BbStudio).  Үндсэн plugin-ий файл, тохиргоог хөндөхгүй, түүнгүйгээр
ч нээгдэнэ (лицензийг үндсэн plugin-оор шалгадаг тул үндсэн plugin суусан, нэвтэрсэн байх ёстой).

СУУЛГАХ:   Revit-ээ хааж, Install.bat-ыг давхар товшино.  Revit-ийг нээхэд «MGL ББ» таб гарна.
УСТГАХ:    Uninstall.bat.  Сурсан стандарт (%APPDATA%\MGL\BbStudio\standard.json) хадгалагдана.

ТОВЧНУУД
  Ажлын зураг үүсгэх   — арматуртай дамнуруу (гинжээр), багана (давхруудаар), цутгамал хана (ЦХ),
                         хучилт (түвшнээр) сонгоход стандартаар дэлгээс, огтлол, төлөвлөгөө үүсгэж
                         хэмжээс, шошго, MRA тавина; хуудсанд байрлуулж (дугаар — 4-/5-/6-/7- цувралын
                         дараагийнх) түүврийг хувилна.  Нэг Ctrl+Z.
  Стандартаар тэмдэглэх — идэвхтэй эсвэл Project Browser-оос сонгосон дэлгээс/огтлол/хучилтын
                         төлөвлөгөөнд тэмдэглэнэ (энэ хэрэгслийн өмнөх тэмдэглэгээг солино).
  Стандарт сурах        — дууссан төслийн ажлын зургаас стандартыг дахин сурна (загварт юу ч бичихгүй).
                         Сураагүй бол ЖИШЭЭ-1-ээс сурсан өгөгдмөл стандарт ажиллана.
  Асуудал – Шийдэл      — Documents\MGL ББ\<төсөл>\Асуудал-шийдэл.xlsx.  Инженер «Шийдэл / Төлөв /
                         Тайлбар» баганыг бөглөж хөгжүүлэгчид илгээнэ; дахин ажиллахад бөглөсөн нь хадгалагдана.
                         Товчоор нээхэд шийдэгдээгүй мөрүүд жагсаалтаар — сонгоод «Харагдац руу очих»,
                         эсвэл «Шийдсэн гэж тэмдэглэх».
