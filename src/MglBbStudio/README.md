# MGL ББ Студи — бүтээцийн ажлын зургийн ТУСДАА Revit нэмэлт

«САЙЖРУУЛАЛТ ББ» (2026-10-19) даалгавар: дууссан төслөөс (ЖИШЭЭ-1) компанийн бүтээцийн ажлын зургийн стандартыг сурч, загварчилсан
арматураас дамнуруу, багана, цутгамал хана, хучилтын дэлгээс/огтлол/төлөвлөгөөг тэр стандартаар үүсгэж тэмдэглэх, хуудсанд байрлуулах,
түүврийг хувилах; асуудлыг «Асуудал – Шийдэл» Excel-ээр солилцох; **өмнөх MGL plugin-ээс тусдаа, түүнийг гэмтээхгүй**.

## Тусгаарлалт (эвдэхгүйн баталгаа)

- Өөрийн assembly (`MglBbStudio.dll`), AddInId (`b6d2f1a4-…`), манифест (`MglBbStudio.addin`), ribbon таб («MGL ББ»), хавтас
  (`%LOCALAPPDATA%\MGL\BbStudio`, өгөгдөл `%APPDATA%\MGL\BbStudio`).  `OnStartup` юу ч уншихгүй; ЦОРЫН ГАНЦ байнгын event =
  «Устгалтын анхааруулга» (`Revit/BbDeleteWatch.cs`): Delete командын `BeforeExecuted` (анхааруулга, Executed-ийг орлохгүй), optional
  устгалтын updater (устгалттай нэг гүйлгээнд DataStorage schema `5921c304-…` — хэн, хэзээ, юуг; Synchronize-оор бүх хүнд очно),
  `DocumentChanged`/`Opened`/`SynchronizedWithCentral` + `Idling` (бусдын шинэ устгалтыг нэг удаа мэдэгдэх).  Бүх алдааг барьж
  `delete-watch-error.txt`-д бичнэ.  Revit-д шалгах: gate `delwatch[:ids=…|n=3]` (устгаад бүртгэлийг уншиж, бүгдийг буцаана).
- Үндсэн plugin-ий арматурын хөдөлгүүрийг (`addin/Reinforcement/{Core,Revit}`, `AutoAnnotate/Core`, `AaDimType`, `RfText`, `Lang`) **ЛИНКЭЭР**
  эмхэтгэнэ — эх код нэг ч мөр өөрчлөгдөөгүй; бүх сайжруулалт хөдөлгүүрийн ОРОЛТ/ГАРАЛТ дээр.  Хана/хучилтын MRA нь хөдөлгүүрийн
  `RfSetMraService` (линкээр).
- Хөдөлгүүрийн `RfSectionStore` (Extensible Storage `com.revitmcp`) хуваалцагдана — огтлолыг аль ч plugin-оор дахин тэмдэглэхэд өмнөхийг солино.
  Дэлгээс, хана, хучилтын тэмдэглэгээ = ӨӨРИЙН бүртгэл `Infra/BbAnnoStore.cs` (schema `5e0b9c37-…`, vendor `MGLE`) — дахин ажиллуулахад
  зөвхөн энэ хэрэгслийн тавьсныг солино, гараар тавьсныг хөндөхгүй.
- Үндсэн plugin-тэй ажиллах үеийн ЦОРЫН ГАНЦ холбоос: лиценз (`Infra/MainPlugin.cs`, reflection → `RevitMcpAddin.Licensing.LicenseGate.Ensure`).
- Хөдөлгүүрийн хуулбар `src/Engine` (жагсаалт `engine-files.txt`, шинэчлэх `tools/sync-engine.ps1`).

## Дамнурууны арматур үүсгэх («Арматур» → «Дамнурууны арматур»)

Ажлын зургийн хэрэгслүүдээс ялгаатай нь энэ хэрэгсэл ЗАГВАРЫН элемент (Rebar) үүсгэнэ.  Жишиг: CADS Rebar Extensions / Naviate Rebar.

| Файл | Үүрэг |
|---|---|
| `Core/BbRebarCode.cs` | БНбД 52-01 / СП 52-101: анкерлах, холбоос, хамгаалах үе, цэвэр зай, хомутын алхам / диаметр, As → n×d (`PickBars`) |
| `Core/BbBeamRebarPlan.cs` | Олон алгаслын дамнурууны төлөвлөгөө (мм, Revit-гүй): үндсэн / нэмэлт / голын / хажуугийн арматур, давхцал, L хөл, консол, хомутын бүс, туслах дамнуруун дахь 3@50 + муруй арматур.  `BbBeamPreset.Company(b)` = ЖИШЭЭ-1-ээс хэмжсэн |
| `Core/BbRebarBook.cs` | Төслийн дэвтэр `%APPDATA%\MGL\BbStudio\rebar\<төсөл>.json` (горим, бетон, ган, марк бүрийн «6Ø25»), LIRA CSV (`марк; As дээд; As доод`, см²) |
| `Revit/BbBeamRebarGen.cs` | Гинж (`BbGeom.BeamChain`) → тулгуур + ачааллын цэг → `Rebar.CreateFromCurves` (R27: `BarTerminationsData`).  Comments = `MGL-BB-GEN`, Partition = «ДАМНУРУУ ДН-n АРМАТУРЧЛАЛ» |
| `Flows/BeamRebarFlow.cs` | Цонх: марк бүрийн мөр, LIRA санал, «гараар тавьсныг солих»; гинж бүр тусдаа transaction (өөрийн undo) |
| `Flows/RebarJob.cs` | АРЫН горим (`RebarJobHost`, «Ажлын зураг гаргах»-ын адил): гишүүн бүр = нэг ExternalEvent, явцын цонх + «Зогсоох».  Revit-д саваа бүр ≈0.3–0.5 с (`CreateFromCurves` ≈185 мс + commit; ЖИШЭЭ-1 ДН-2 142 элемент — 79 с), бүх загвар хэдэн цаг тул заавал арын горим |
| `Gate/GateRebar.cs` | gate `rebargen:mark=ДН-8|ДН-9;replace=1;dump=1` (эсвэл `mark=all;limit=N`, `code=1` = нормын горим); `colrebargen:` — баганад адилхан |
| `Core/BbColumnRebarPlan.cs` | Баганы төлөвлөгөө: nb×nh периметрээр, дээд давхар ижил огтлолтой бол дээд нүүрээс дээш давхцал, эс бол зангилаанд L (огтлол өөрчлөгдвөл dowel-ын анхааруулга), гадна битүү + C-хомут, доод (≥ давхцал) / дээд нягт бүс.  `BbColumnPresets.Company/Code` |
| `Revit/BbColumnRebarGen.cs`, `Flows/ColumnRebarFlow.cs` | «Баганын арматур»: `BbColumns.Stack` → давхар бүрийн элемент, зангилаа = дээд нүүрт тулсан хамгийн гүн дамнуруу / хучилт; марк бүрийн «4×4Ø20» |
| `Revit/BbBeamRebarGen.cs` → `BbRebarBuilder` | Нийтлэг: bar type (Ø + ган нэрээр), hook type (өнцөг + хэв маяг), `CreateFromCurves` (дэгээний 4 чиг туршина), Comments / Partition, layout |

**Хоёр систем:** «Рамын холбоост систем (strong column)» = ЖИШЭЭ-1/3-аас сурсан (`Company`), «Энгийн каркас» = ЖИШЭЭ-4-өөс
хэмжсэн (`BbBeamPreset.Ordinary`; хомут Ø8 @100 тулгуураас ¼l, гол @200 төвд; тулгуурын дээд ⅓l (50-ийн ойрын үржвэр), голын Ø12 түүнтэй 500
давхцана; хажуугийн Ø12 h ≥ 500).  Аль алинд нь **норм зөрчихгүй** (`EnforceCode`): хамгаалах үе &lt; нормын → нормын, давхцал = max(хүснэгт, норм), алхам &gt; дээд
хязгаар → хязгаар (анхааруулгатай).

**Уян хатан байдал (CADS / Naviate / Alpha BIM-тэй харьцуулж):**
- Хомутын хэлбэр сонгох — дамнуруу: нэг битүү / хоёр давхардсан (ЖИШЭЭ-1) / гадна + дотоод / гадна + босоо C; багана: гадна / хосын тэгш
  өнцөгт (ЖИШЭЭ-1) / ширхэг бүрд C / ээлжлэн C / гадна + дотоод.
- Хажуугийн арматур «2Ø12» (тал бүрд эгнээ × Ø), «0» = байхгүй; C-хомуттай.
- Хамгаалах үе = элементийн «Rebar Cover - Top / Bottom / Other» (сонголтоор).
- Алгасал бүрийн хүснэгт: асаах / унтраах (зөвхөн сонгосныг үүсгэнэ, `MGL-BB-GEN s1-3` тэмдэгтэй — давхцсаныг л солино), тулгуур бүрийн
  нэмэлт дээд, алгаслын нэмэлт доод, s1 / s2.
- Хувьсах огтлолтой гинж (Alpha BIM маягаар): огтлол бүрийн хэсэг тусдаа мөр «ДН-37 (600×500)», тулгуургүй залгаасанд арматур хөрш хэсэг
  рүү анкерлах уртаар шулуун (`JoinStart` / `JoinEnd`).
- «Энэ мөрийг ижил огтлолтой бүгдэд хуулах»; урьдчилсан фасад + огтлол (унтраасан алгасал саарал).
- Gate `rebargen:…;time=1` — үүсгэх / layout / тэмдэглэх / commit-ийн мс.
- Gate `rebarcompare:mark=all` — жишээ (гараар) арматуртай гинж бүрд манай төлөвлөгөөг тулгана (хомутын байрлалын таарц ±30 мм, тоо / их алхам,
  огтлолын ширхэг, урт); `detail=ДДН` — станц бүрийг хэвлэнэ.

**Загвараас сурах хэв маяг** (`Core/BbRebarStyle.cs`, `Revit/BbRebarLearn.cs`): хоёр горимд ч загварт гараар тавьсан арматураас төслийн
тохиргоог уншиж анхдагчийг солино (дэвтэрт `style` / `colStyle` болж хадгалагдана, цонхонд асаах / унтраах).  Дамнуруу: хомутын Ø (огтлолоор),
C-хомутын Ø ба нүүрээс зай, хажуугийн Ø, bar type-ийн нэр (үүрэг + Ø), хамгаалах үе (дээд нь гинжийн ЧИГЛЭЛЭЭР — огтлолцолд нэг чиглэлийн дээд
арматур нөгөөгийнхөөс доогуур: ЖИШЭЭ-1 32 / 52, ЖИШЭЭ 3 30 / 50), муруй арматурын тоо (өргөнөөр), @150 шилжилт ба туслахын хажуугийн @100 зурвас —
сүүлийн хоёрыг хоёр хувилбараар төлөвлөж жишээтэй ИЛҮҮ ТААРСНЫГ сонгоно.  Багана: хомутын хамгаалах үе, саваа нүүрээс, Ø / алхам, эхний / сүүлийн
хомут, залгаасын өндөр (давхрын өндрөөр), тал дахь ширхгээр дотоод хосын тоо.

Жишээнээс хэмжсэн нийтлэг дүрэм (ЖИШЭЭ-1 ба 3): нягт бүсийн завсар = round((l/3 − 50) / 100), гол = floor(l/3 / 200) голд төвлөрсөн; дээд / голын
арматурын төгсгөл нүүрээс 50-ийн үржвэр; туслах дамнуруу бүрийн нүүрээс 3@50, туслах хоорондох гол хэсэг @200 голдоо; C-хомут Stirrup/Tie
хэв маягаар («C хомут» хэлбэр); 300-аас нимгэн хөндлөн хана тулгуур биш; хазайсан дамнуруу solid-оор хэмжинэ (world bbox хэт өргөн).
Харьцуулалт (хомутын байрлал ±30 мм): ЖИШЭЭ-1 дундаж 0.84, 706-аас 208 алгасал яг таарсан; ЖИШЭЭ 3 — 0.73, 1126-аас 276;
ЖИШЭЭ-4 («Энгийн каркас») — 0.34 → 0.87 (медиан 0.98), хомутын тоо 1.00, урт 1.01.

**Өндөр нь өөр, өргөн / дээд нүүр ижил хэсгүүд** (ЖИШЭЭ-4 ДН-4 400×600 / 400×500, `ContinueTops`): баганын дээд арматурыг зүүн хэсэг тавьж
баруун хэсгийн алгаслын ⅓ хүртэл (консол бол үзүүр хүртэл, консолын өндрөөр хөлтэй) тасралтгүй үргэлжлүүлнэ; баруун хэсэг тэр баганад тавихгүй
(`BbBeamInput.ContinueTopEnd / ContinueTopStart`).  Хөрш нь гүн бол доод арматур хөлгүй, баганыг дайрч алс нүүрээс 100 (анкерлах уртаас
багагүй) гүн хэсэгт шулуун зоогдоно (`StraightBottomStart / End`; ЖИШЭЭ-4 FX2–FX3).

Хэрэглэгчийн зассан ДН-4-1-ээс (`Ordinary`): C-хомут хоёр хажуугийн хамгаалах үеийн хооронд (`TieAtCover`, B = 360 — хос хомутад эхний хомутын
хүрээгээр 230 болж байсан алдаа засагдсан); 600 өндөрт ч хажуугийн 1 эгнээ (`SidePitch` 300); консолын доод нь үзүүрт дээш хөлтэй, тулгуурт
шулуун (`CantileverBottomTipHook`), дээдийн үзүүрийн хөл доод эгнээнээс 30 дээш (`TipHookClear`).  Туслах дамнуруу тулсан газарт ЖИШЭЭ 3 шиг
муруй арматур (анхдагч 3 / 5 Ø16, загвараас сурсан бол түүнийх — ЖИШЭЭ-4: 3Ø12) ба нүүр бүрээс 3@50.  Голын тулгуур дээр доод арматур
алгаслаар тасарч баганын алс нүүрээс 100 гарна (`BottomThroughSupport`, хэрэглэгч; ДН-7 жишээтэй таарна).  Консолын үзүүрийг хөндлөн (хаалтын)
дамнуруу дайрвал арматур түүний алс нүүрээс хамгаалах үе + d/2 дотор хүртэл (`TipExtStart / End`, `TipCrossing`; ДН-4 / ТДН-3).

Хэрэглэгчийн ДН-4-2 / ДН-3-аас (0.2.0.70, `Ordinary`): маталтын харагдах урт бүхэл (`NiceLengths`; Revit-ийн A/B/C = тэнхлэг + d/2 — хэмжиж
баталсан: 470 → C = 480; ≥ 200 бол 50-ийн, бага бол 10-ын ойрын үржвэр; 46 хэлбэрт налуу хэрчмийн нугалаа нэмэгддэг тул үүсгэсний дараа
A/B/C-г уншиж нэг удаа засна → 500 / 500 / 400); гүн хөрш рүү шулуун доод нь зөвхөн алс нүүрээс 100 (`StraightBottomShort`, хэрэглэгч: норм
заавал биш); захын тулгуурын дээд хөл баганад доош орж болно (`TopHookIntoColumn`); хажуугийн арматур өндрөөр — 1 бол яг голд, олон бол H/(n+1),
ирмэгээс бүхэл (`SideByHeight`); муруйн доод хэвтээ туслахын доод нүүрт, дээд нь дээд эгнээний доор (`BentOnSoffit`).

**Цонхны загвар** (`Flows/BbTheme.cs`): цэнхэр толгой мөр, цайвар дэвсгэр, цагаан карт хэсгүүд, үндсэн (цэнхэр) / туслах товч, цайвар цэнхэр
толгойтой хүснэгт — дамнуруу ба баганын арматурын цонх.  Логик өөрчлөгдөөгүй.

**Хамгаалах үеийн урхинууд (хэмжсэн, хэрэглэгчийн зураг 1 / 2):**
- Битүү хомутыг битүү 4 хэрчмээр өгвөл Revit 51 хэлбэрт тааруулахдаа зарим талыг d/2-оор дотогш татдаг (дамнуруунд сүүлийн 2 тал, баганад 4 тал)
  → `BbRebarBuilder.CreateLoop`: нээлттэй хүрээ (давхцах үзүүрүүд эхний булангаас d/2 гадагш — Revit-ийн гараар тавьсантай адил), `Regenerate`
  хийж бодит тэнхлэгийг хэмжиж, зөрвөл засвартай дахин үүсгэнэ (засвар чиглэл / Ø-ээр кэштэй).
- Хөлтэй ажлын арматурын хөлийг Revit 12 мм хүртэл шилжүүлдэг → `CreatePath` (адил хэмжиж засна; regenerate-гүйгээр хэмжвэл оролтоо л буцаана).
  Консолын шулуун үзүүрийг Revit d/2 хүртэл дотогш тайрдаг — анхааруулахгүй.  Баганын ажлын арматурт (ЖИШЭЭ-4-ийн 47 м багана) засвар
  тогтворжихгүй тул энгийн үүсгэлт хэвээр — нээлттэй.
- Арматурын үзүүрийн тэнхлэг нүүрээс хамгаалах үе + d/2 (тэнхлэгийг хамгаалах үеийн шугамд тавивал гадна тал нь d/2-оор хэтэрнэ).
- Гэр бүлийн bbox нэмэлт геометрээр өндөр болдог (ЖИШЭЭ-4 «400 x 500»: bbox 1550) → төрлийн «h» solid-той таарч bbox-той таарахгүй бол өндрийг
  solid-оос (`TrueExtent`).  Хэвтээ чиглэлд bbox хэвээр: solid нь баганын нүүрээр огтлогдсон тул ЖИШЭЭ 3-ын таарц 276 → 229 болж байв.
