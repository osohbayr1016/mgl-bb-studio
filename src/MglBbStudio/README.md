# MGL ББ Студи — бүтээцийн ажлын зургийн ТУСДАА Revit нэмэлт

«САЙЖРУУЛАЛТ ББ» (2026-10-19) даалгавар: дууссан төслөөс (ЖИШЭЭ-1) компанийн бүтээцийн ажлын зургийн стандартыг сурч, загварчилсан
арматураас дамнуруу, багана, цутгамал хана, хучилтын дэлгээс/огтлол/төлөвлөгөөг тэр стандартаар үүсгэж тэмдэглэх, хуудсанд байрлуулах,
түүврийг хувилах; асуудлыг «Асуудал – Шийдэл» Excel-ээр солилцох; **өмнөх MGL plugin-ээс тусдаа, түүнийг гэмтээхгүй**.

## Тусгаарлалт (эвдэхгүйн баталгаа)

- Өөрийн assembly (`MglBbStudio.dll`), AddInId (`b6d2f1a4-…`), манифест (`MglBbStudio.addin`), ribbon таб («MGL ББ»), хавтас
  (`%LOCALAPPDATA%\MGL\BbStudio`, өгөгдөл `%APPDATA%\MGL\BbStudio`).  `OnStartup` юу ч уншихгүй, event бүртгэхгүй.
- Үндсэн plugin-ий арматурын хөдөлгүүрийг (`addin/Reinforcement/{Core,Revit}`, `AutoAnnotate/Core`, `AaDimType`, `RfText`, `Lang`) **ЛИНКЭЭР**
  эмхэтгэнэ — эх код нэг ч мөр өөрчлөгдөөгүй; бүх сайжруулалт хөдөлгүүрийн ОРОЛТ/ГАРАЛТ дээр.  Хана/хучилтын MRA нь хөдөлгүүрийн
  `RfSetMraService` (линкээр).
- Хөдөлгүүрийн `RfSectionStore` (Extensible Storage `com.revitmcp`) хуваалцагдана — огтлолыг аль ч plugin-оор дахин тэмдэглэхэд өмнөхийг солино.
  Дэлгээс, хана, хучилтын тэмдэглэгээ = ӨӨРИЙН бүртгэл `Infra/BbAnnoStore.cs` (schema `5e0b9c37-…`, vendor `MGLE`) — дахин ажиллуулахад
  зөвхөн энэ хэрэгслийн тавьсныг солино, гараар тавьсныг хөндөхгүй.
- Үндсэн plugin-тэй ажиллах үеийн ЦОРЫН ГАНЦ холбоос: лиценз (`Infra/MainPlugin.cs`, reflection → `RevitMcpAddin.Licensing.LicenseGate.Ensure`).
- Хөдөлгүүрийн хуулбар `src/Engine` (жагсаалт `engine-files.txt`, шинэчлэх `tools/sync-engine.ps1`).

## Бүтэц

| Хавтас | Агуулга |
|---|---|
| `Core/` | Revit-гүй цэвэр код (тест `tests/BbStudio.Tests`): стандарт (`BbStandard` — дамнуруу/туслах/багана + `BbPlateStandard` хана/хучилт + `BbSheetStandard` хуудас/цуврал), сурах статистик (`BbLearnStats`), байрлалын математик, MRA-ийн байрлал (`BbMraLayout`), JSON, XLSX, «Асуудал – Шийдэл» (`BbIssues`) |
| `Revit/` | `BbLearner` (стандарт сурах), `BbViews` (дамнуруу), `BbColumns` (багана), `BbPlates` (хана, хучилт), `BbAnnotate` + `BbElevMra` + `BbBarChain` + `BbGridDims` (тэмдэглэх), `BbDatums` + `BbCrop` (түвшин/тэнхлэгийн шугам, тэмдэглэгээний crop), `BbSheets` + `BbSheetSeries` (хуудас, дугаарын цуврал), `BbSchedules` (түүвэр хувилах) |
| `Flows/` | 4 командын урсгал (`Flows.cs`, `IssuesFlow.cs`) |
| `Infra/` | `BbStore` (стандарт/Excel зам), `BbAnnoStore`, `BbDialog` (XAML-гүй WPF), лиценз, ribbon дүрс |
| `Gate/` | Хөгжүүлэгчийн тусгаар Revit-ийн шалгалт (`MglBb.Gate.Entry.Run`) — хэрэглэгчид хамааралгүй |
| `Resources/standard-default.json` | ЖИШЭЭ-1-ээс сурсан өгөгдмөл стандарт (embedded) |

## ЖИШЭЭ-1-ээс хэмжиж хэрэгжүүлсэн дүрмүүд

- **Огтлолын гинж** «нүүр | хомут | ажлын арматур бүрийн төв | хомут | нүүр» (`BbBarChain`): лавлагаа = ширхгийн харагдацын «загалмай» далд шугам
  (`…:1106ddd` / `…:1103ddd`), ЧИГЛЭЛЭЭР сонгоно.  Эхлээд бүх загалмайгаар, утга таарахгүй бол зөвхөн ЯГ тэгш (≤ 2.5°) лавлагаагаар; дутуу бол
  хомутын гинж хэвээр (баганын доод давхрын хазайлгасан ширхгийн загалмай 18–45° эргэсэн байдаг — Б-5 S4/S7).
- **Дэлгээсийн MRA** (`BbMraLayout`, 235 дэлгээсээс): богино бүс гишүүнд ойр эгнээ, урт/дунд хол эгнээ; толгой шугамаас гишүүн рүү.
- **Багана**: давхар бүрийн стек, хэсэг ≤ 330 мм цаас (A2-ын өндөр), нэр «БАГАНА  Б-5 АРМАТУРЧЛАЛ   /+4.93-+21.43/»; хэсэгт харагдах
  БҮХ давхрын арматурыг НЭГ контекст болгож тэмдэглэнэ (түвшний гинж, хомутын MRA бүх давхарт).  Огтлол дээрээс, зөвхөн тохиргоо өөрчлөгдсөн давхарт.
- **Хана (ЦХ-n)**, 6-n хуудас: хэв + арматурчлалын дэлгээс (1:50 хуудсанд багтвал, үгүй бол 1:100), хэвний босоо огтлол 1:100, хэвтээ огтлол
  хэв 1:50 + арматур 1:25 (ханын эхний 3.5 м, доод давхрын голд).  Арматурчлалд олонлог бүр «Middle» + MRA «(Поз)⌀Диаметр-Алхам»;
- **Дамнурууны дэлгээс** (ЖИШЭЭ turshilt1 ДН-5, 2026-10-23, инженер vs plugin тайлангаар): MRA-ийн шугам доод нүүрнээс ≥ `StirrupDimOffsetPaperMm`
  (22.5), бүс хоорондын 150 / «50 | 400 | 50» болон захын баганын «400 | 50» тэр шугам дээр, тэнхлэгийн гинж түүнээс нэг алхам; дээд талд давхцал
  нүүрнээс `ElevDimFirstPaperMm` (9.5 — сурахдаа ЗӨВХӨН дээд талын эгнээгээр), гинж түүнээс нэг алхам; нугалсан дээд арматурын давхцлыг өөрсдөө
  зурна (хөдөлгүүрт үзүүрийн лавлагаагүй); гинжид давхцлын хоёр үзүүрээс зүүнийг л.  Нугалсан арматурын шошго гол шулуун хэсгийн талын эгнээнд;
  leader гол шулуун хэсэг дээр; дээд шошгыг хэмжээсийн туслах шугам дайрвал арматурын дагуу зөөнө.  Гараар тавьсан төгсгөлийн тэмдгийг сурахад
  тооцно.  ⚠️ Гинжин хэмжээст баганын нүүрний лавлагааг Revit заримдаа ХАСДАГ (ижил кодоор 8 / 7 / 6 сегмент) — сегмент дутуу бол буцааж,
  Regenerate хийгээд лавлагааг шинээр авч дахин (`BbElevTopChain`).  Туслах дамнуруу (ТДН-4, ТДН-2): нэг бүстэй ч захын «250 | 75»; захын тулгуур
  нь огтлолоор харагдах дамнуруу ч болно («25 | 300»); тэнхлэг ганц бол «тулгуурын гадна нүүр | тэнхлэг | тулгуурын гадна нүүр» MRA-аас нэг алхам
  доош (хөдөлгүүр 2-оос цөөн тэнхлэгт гинж зурдаггүй).  ЖИШЭЭ 3 (ТДН-1-5, 1-6, 2026-10-23): ⚠️ налуу (3°) тулгуурын нүүрийн SURFACE
  лавлагаа commit-д «invalid reference» болж БҮХ тэмдэглэгээг буцаадаг — огтлолын босоо ирмэг (`…:24:CUT_EDGE/5`, харагдацын геометрийн
  Edge.Reference); нүүрний R = хавтгай харагдацын хавтгайг огтлох цэг (`PlaneR`); ⚠️ CUT_EDGE-тэй хэмжээсийг дараагийн Regenerate 4.75 м доош
  шилжүүлдэг (тусад нь давтагддаггүй) — commit-ийн өмнө `BbElevStirrupDims.Restore`; ⚠️ хөдөлгүүр шошгыг олонлогийн 0-р ширхэгт холбодог —
  ЖИШЭЭ 3-т зөвхөн дунд ширхгийн шошго харагддаг (геометрээр таах дүрэм олдоогүй) → харагдацын цуглуулгаар шалгаж дунд/бусад ширхэгт дахин
  үүсгэнэ (`BbElevRules.RetargetHiddenBars`, толгойг Create-ийн дараа онооно).  Тулгуур дамнуруунаас эхэлсэн дээд гинжийг сурна; нугалсан
  арматурын давхцал гинжгүй ч; break family нэр бага зэрэг өөр бол («…Line1») эхлэлээр.  Commit буцаагдвал Revit-ийн алдааг асуудалд бичнэ.
  ТДН-1-8/1-9: тулгуурын нэг тал гишүүнтэй нийлсэн бол гишүүний хэвтээ огтлолын ирмэгийн ҮЗҮҮР («…:24:CUT_EDGE/1/3»); ⚠️ хуучин хэмжээсийн
  тэнхлэгийн лавлагаа («…:0:SURFACE») шинэ хэмжээсэд «Invalid number of references» — `new Reference(grid)`; ⚠️ тулгуурын CUT_EDGE-ийг stable-аар
  дахин уншвал өөр байрлалд бууна — эхээр нь; тэнхлэгийн гинж захын тулгуурын гадна нүүр хүртэл; завсрын тулгуур = багана эсвэл ЭНЭ гишүүнээс
  нарийн биш эсрэг дамнуруу (нарийн = хоёрдогч, тулгуур биш); богино бүсийн хажуугийн зайг сурна (`ElevStirrupGapsShort`); дээд гинжинд
  тэнхлэг оруулахыг сурна (`ElevTopChainGrids`).  ДДН-3/ТДН-1-11 (2026-10-23): ⚠️ «Стандарт сурах» OwnerViewId-аар цуглуулдаг тул НУУГДСАН
  хуучин тэмдэглэгээг ч тоолж байв (ТДН-1-11 давхцал 11 → 9) — заасан горимд харагдацын цуглуулгаар шүүнэ; туслах дамнуурын дээд гинжинд тэнхлэг
  оруулахгүй (компанийн дүрэм); давхцлын хоёр үзүүр гинжинд үлдэнэ (ББ инженер); тэнхлэгийн гинж — гишүүн бүрийнхийг НЭГ болгож, консол бол
  дамнурууны төгсгөл хүртэл, `ElevGridChainToSupport` (сурна) бол тэнхлэгтэй тулгуурын гадна нүүр хүртэл; тулгуурын хэмжээст тэнхлэг —
  `ElevGapGrid` (сурна: ЖИШЭЭ 3 ДДН-3 тийм, turshilt1 ДН-5 үгүй); 12° хүртэл налуу тулгуур (огтлолын ирмэгээр); haunch гишүүний төгсгөл = босоо
  ирмэг (LINEAR); олон өндөртэй гишүүнд хэмжээс тухайн гишүүний хамгийн доод MRA-ийн мөрөнд; CUT_EDGE-тэй хэмжээсийг эцсийн transaction-д дахин
  байранд нь (`Restore`, зорьсон мөрөөр).
  хоёр дэлгээсэд тэнхлэгийн гинж + нийт, түвшний гинж.
- **Хучилт** (түвшнээр), 7-n хуудас: «4.93 ТҮВШНИЙ ХУЧИЛТЫН ХЭВНИЙ БАЙГУУЛАЛТ / ДООД / ДЭЭД ҮЕИЙН АРМАТУРЧЛАЛ» 1:120, хуудас бүрт нэг;
  олонлог бүрд MRA «(Поз)Тоо/ш-⌀Диаметр-Алхам», тэнхлэгийн 4 гинж.  Түвшний текст = өндөр (түвшний нэр «Давхар 2» тул).  Хучилтын огтлолын
  (1:20) байрлалыг инженер сонгоно — автоматаар үүсгэхгүй.
- **Хуудас**: A2 «Булангын_хүснэгт_2021 : E@C A2»; дугаар = цувралын дараагийн чөлөөт (4- багана, 5- дамнуруу, 6- хана, 7- хучилт),
  «* Classification / * Sub-Discipline / * Type Designator» + зохиогч/шалгагчийг тэр цувралын сүүлийн хуудаснаас.  Дэлгээс дээрээс (хана зүүн тийш),
  огтлол дэлгээсийн баруун талын чөлөөнд эсвэл доор мөр мөрөөр; гарчиг зургийн доор шууд.  Хэмжээ = crop + өөрийн тэмдэглэгээ + түвшин/тэнхлэгийн
  толгой; түвшин/тэнхлэгийн шугамыг харагдац бүрт crop-ын ирмэгт тайрна (view-specific), тэмдэглэгээний crop идэвхтэй.
- **Түүвэр**: тухайн цувралын хуудсанд байрласан гишүүний түүврийг («201.ББ.РАМ.АРМАТУР Дн-1» Partition, «204 … БЕТОН» Mark …) «үүрэг» болгож
  хувилна, нэр болон шүүлтүүрийн утган дахь тэмдгийг солино; байгаа бол дахин ашиглана; хоосон гарвал асуудал (Partition-ийг тохируулах санал).
  Хуудсанд багтахгүй бол тусдаа «… ТҮҮВЭР» хуудас; хуудаснаас өндөр бол асуудал.
- **Стандарт сурах**: харагдац бүрийн цуглуулгын оронд нэг удаагийн индекс; нэрэнд тэмдэггүй босоо «Detail» харагдац баганы дэлгээс гэж тоологдохгүй;
  хана/хучилтын харагдацын төрөл, загвар, масштаб, MRA-г нэрээр нь танина.

## Шалгах

```
cd tests/BbStudio.Tests && dotnet run                   # цэвэр тест
powershell -File src/MglBbStudio/package.ps1             # R24–R27 бүтээлт + dist/<v>/MGL-BB-Studio-<v>.zip
```

Revit дээрх шалгалт: хөгжүүлэгчийн ТУСДАА Revit 2024 (загварын ХУУЛБАР, хэзээ ч хадгалахгүй) + harness add-in → `Gate/GateOps.cs`
(`flow` — тэмдэг/түвшнээр бүтэн урсгал, `ui` — цонхтой урсгал (UIA driver дарна), `learn`, `plates`, `barrefs`, `img` …).  Хэрэглэгчийн Revit-д ХЭЗЭЭ Ч ажиллуулахгүй.

## Үлдсэн ажил

- Хучилтын огтлол (1:20) ба хучилтын түүвэр (шүүлтүүр нь «Бүлэглэл»/түвшний текст — тэмдэггүй) автоматаар хийгдэхгүй.
- Хана: хэвтээ огтлолын MRA-ийн шошго ойрхон давхцаж болно (хөдөлгүүрийн байрлал).
- Хуудасны дугаар — цувралын дараагийн чөлөөт; зургийн жагсаалтын дарааллаар (тэмдгийн дарааллаар) дахин дугаарлахгүй.
