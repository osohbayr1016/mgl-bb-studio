# MGL AI · суулгагч

Ажилтан **нэг .exe татаж, юу ч асуухгүйгээр** суулгаад, ERP-ийн MGL AI
хуудсыг нээхэд шууд ажиллана.  Түлхүүр, нууц үг, порт, загварын зам —
**юу ч оруулахгүй**.

```
[Веб хуудасны «MGL AI татах»] → MGL-AI-Setup.exe → суулгана → ERP нээнэ → бэлэн
```

---

## Яагаад ийм бүтэцтэй вэ

### Хоёр bucket, хоёр өөр шалтгаан

| Хаана | Юу | Яагаад |
|---|---|---|
| **`MEDIA_BUCKET`** (нийтийн, нэвтрэлтгүй) | `node`, `llama.cpp`, `runtime-code`, `mgl-ai-components.json` | Нээлттэй эхийн дахин түгээгддэг файл ба бидний код.  **Нийтэд байснаар суулгагч ямар ч итгэмжлэлгүй ажиллана** — тэр нь «API key асуухгүй» шаардлагыг биелүүлэх цорын ганц зам. |
| **`MEETING_BUCKET`** (хувийн, нэвтрэлттэй) | суулгагчийн `.exe`, **загварын жин**, адаптер | Загварын жин нь лицензтэй артефакт; нийтэд тавих нь арилжааны дахин түгээлт.  Суулгагч нь ажилтны хэрэгсэл тул мөн хувийн. |

⚠️ **`/media/:key` нь ЯГ НЭГ сегмент таарна** (репогийн мэдэгдэж буй зан
төлөв).  Тиймээс нийтийн түлхүүрт `/` байж **болохгүй**:
`mgl-ai/node.zip` → 404, `mgl-ai-node-24.18.0.zip` → ажиллана.

### Загварыг суулгагч ТАТАХГҮЙ

Суурь загвар (4–5 GB) нь **вэб хуудас хосолсны дараа** татагдана:

1. Ажилтан ERP-д нэвтэрсэн байна.
2. MGL AI хуудас нээгдэхэд `POST 127.0.0.1:39217/pair` рүү өөрийн
   токеныг дамжуулна (ажилтан юу ч харахгүй).
3. Локал runtime тэр токеноор манифест шалгаж, загвар/адаптер/нормыг
   татна.  Явц нь хуудсан дээр «MGL AI-г бэлдэж байна · 37%» гэж гарна.

Ингэснээр суулгагч нь **60 KB**, суулгац нь **2 минут** болно —
5 GB-ыг installer дотор явуулах хэрэггүй.

## Бүтээх

```powershell
powershell -ExecutionPolicy Bypass -File installer\build.ps1 -Version 1.0.0
```

`installer\dist\MGL-AI-Setup-1.0.0.exe` (+ SHA-256) гарна.

⚠️ **Гарын үсэггүй хоёртын файл.**  SmartScreen эхний удаа сануулна.
Үүнийг «SmartScreen унтраа» гэж заавраар БҮҮ засаарай — код гарын
үсгийн гэрчилгээ авах нь зөв шийдэл.

⚠️ IExpress (`C:\Windows\System32\iexpress.exe`) нь Windows бүрд байдаг
тул нэмэлт хэрэгсэл **шаардахгүй**.  Inno Setup / NSIS илүү сайхан
суулгагч гаргадаг ч энэ машинд байхгүй бөгөөд хоёр файл задалж нэг
тушаал ажиллуулах ажилд build хамаарал нэмэх нь зохисгүй.

## Нийтлэх

### 1. Хэсгүүдийг бэлдэх (нэг удаа)

`node` ба `llama.cpp` -г **гараар** татаж, шалгаад дараах JSON бичнэ
(`components.local.json`):

```json
[
  { "component": "node",       "version": "24.18.0", "path": "C:/tmp/node-v24.18.0-win-x64.zip" },
  { "component": "llama-cuda", "version": "b10850",  "path": "C:/tmp/llama-b10850-bin-win-cuda-x64.zip" },
  { "component": "llama-cpu",  "version": "b10850",  "path": "C:/tmp/llama-b10850-bin-win-cpu-x64.zip" }
]
```

⚠️ **CUDA архивын дотор `cudart64_*.dll`, `cublas64_*.dll` байгаа
эсэхийг ЗААВАЛ шалга.**  llama.cpp-ийн release нь тэдгээрийг **тусдаа**
`cudart-…` архивт тавьдаг — мартвал загвар чимээгүйхэн CPU дээр
ажиллаж, «MGL AI удаан» гэсэн оношлоход хэцүү гомдол үүснэ.  Хоёр
архивыг нэг zip болгож нийлүүлээрэй.

### 2. Багцлах, бүртгэх

```bash
cd ai
node scripts/publish-installer.mjs \
  --pack-runtime \
  --components ../components.local.json \
  --installer ../installer/dist/MGL-AI-Setup-1.0.0.exe --version 1.0.0
```

Энэ нь **юу ч хийхгүй**, зөвхөн тушаал + SQL хэвлэнэ.  Шалгаад
`--apply` нэмнэ.

### 3. D1-д бүртгэх

Скриптийн хэвлэсэн `wrangler d1 execute …` мөрүүдийг `backend/`
хавтаснаас ажиллуулна.  Тэдгээр нь `ai_runtime_installers`-д
`is_active = 1` мөр үүсгэнэ — вэб хуудасны «MGL AI татах» товч
тэндээс уншина.

## Локал туршилт (сүлжээгүйгээр)

```powershell
# Манифест нь file:// байж БОЛНО — татах хаягуудыг локал зам болгоно.
powershell -ExecutionPolicy Bypass -File installer\bootstrap.ps1 `
  -ManifestUrl "file:///C:/Users/User/project/mgl-e-c/ai/dist/mgl-ai-components.json"
```

Багцалсан runtime нь бие даан ажиллах эсэхийг шалгах:

```powershell
Expand-Archive ai\dist\mgl-ai-runtime-1.0.0.zip -DestinationPath $env:TEMP\mglai-test
$env:MGLAI_PORT='39230'; $env:MGLAI_ENGINE='echo'
node "$env:TEMP\mglai-test\runtime\src\server.ts"
# өөр цонхноос:  curl http://127.0.0.1:39230/health
```

## Суулгагч ЮУ ХИЙДЭГ

| Алхам | Хаана | Тэмдэглэл |
|---|---|---|
| Node 24 (зөөврийн) | `%LOCALAPPDATA%\MglAi\node` | Ажилтны PATH дээрх Node-д **найдахгүй** — хуучин Node нь TypeScript шууд ажиллуулж чадахгүй ба алдаа нь эвдэрсэн суулгац мэт харагдана. |
| llama.cpp | `…\MglAi\bin` | GPU байвал CUDA, эс бөгөөс CPU build.  `nvidia-smi` олдохгүй нь **«GPU байхгүй» гэсэн үг биш**, «мэдэхгүй» — тиймээс CPU build (удаан ч зөв). |
| Runtime код | `…\MglAi\app` | **Бүхэлд нь солино.**  Хагас шинэчлэгдсэн runtime нь оношлох боломжгүй алдаа өгнө. |
| Автомат эхлүүлэлт | Task Scheduler (**хэрэглэгчийн**, admin эрхгүй) | Нэвтрэх бүрд **хөнгөн** Node процесс асна, **унавал 1 минутын дотор сэргэнэ** (`RestartCount 10`), Task Manager-аас хаасан ч 10 минут тутмын хяналтын триггер буцааж асаана (ажиллаж байвал `IgnoreNew` тул юу ч хийхгүй).  **Загвар АЧААЛАГДАХГҮЙ** — тэр нь ERP нээгдэхэд (`useMglAiPrewarm`, сүүлийн 14 хоногт AI хэрэглэсэн хөтөч дээр) эсвэл MGL AI хуудас нээгдэхэд (`/warmup`) болно. |
| Дэлгэцийн товчлол | Desktop | Task Scheduler бодлогоор хаагдсан үеийн сэргээх зам. |

Бүгд **`%LOCALAPPDATA%`-д, админ эрхгүй**.  Elevation шаардах нь админ
эрхгүй ажилтны машин бүр дээр суулгацыг зогсооно.

⚠️ **Файл бүр SHA-256-аар шалгагдана, алгасах туг БАЙХГҮЙ.**  40
машин дээр ажиллах баталгаажаагүй хоёртын файл нь энэ бүтээгдэхүүний
хамгийн үнэ цэнэтэй халдлагын бай.

## Шинэчлэлт

| Юу | Хэмжээ | Хэрхэн |
|---|---|---|
| Норм / мэдлэг | ~5 MB | `ai_knowledge_packs`-д мөр нэмнэ.  Runtime 6 цаг тутам шалгана.  **Загвар дахин ТАТАГДАХГҮЙ.** |
| Адаптер (MGL AI 1.1 → 1.2) | ~200 MB | `ai_model_releases`-д `kind='adapter'` мөр.  Автоматаар татагдаж, smoke тест давбал идэвхжинэ, унавал **буцна**. |
| Runtime код | ~150 KB | `--pack-runtime` → шинэ `runtime-code` мөр. |
| Суурь загвар | 4–5 GB | **Автоматаар СОЛИГДОХГҮЙ** — зөвхөн огт байхгүй үед татна.  Шилжилтийг админ зориуд эхлүүлнэ. |

⚠️ Ажилтан **юу ч дарахгүй**.  Хуудсан дээр «MGL AI шинэчлэл татаж
байна · 37%», дараа нь «MGL AI 1.2 болж шинэчлэгдлээ» гэсэн мөр л
гарна.
