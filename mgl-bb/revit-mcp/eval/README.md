## 1. Гурван багц — юу нь хаана байдаг вэ

| Багц | Хаана | Сургалтад ордог уу | Хэн өөрчилдөг вэ |
|---|---|---|---|
| **CURATED-TRAIN** | `revit-mcp/training/data/*.json` (`report*.json`-оос бусад) | ✅ | Хэн ч — PR-аар |
| **GOLDEN-EVAL** | `eval/golden/{intents,bim,rules,difficult_cases,adversarial}.json` | ❌ **ХЭЗЭЭ Ч** | Зөвхөн `freeze.py` |
| **GOLDEN-REGRESSION** | `eval/golden/regressions.json` | ❌ **ХЭЗЭЭ Ч** | Зөвхөн `freeze.py add-regression` |

**Ердийн сургалтын дамжуулга GOLDEN-EVAL-ыг ХЭЗЭЭ Ч өөрчлөхгүй.**
`pull_and_retrain.py` → `train_intent.py` → `check_*.py` гинжин хэлхээний
аль ч алхам `eval/`-д БИЧИХГҮЙ.  Бичдэг цорын ганц зам нь ХҮНИЙ гараар
ажиллуулсан `freeze.py`.

|---|---|
| `assert_paths_not_golden(paths)` | `eval/golden/` доорх ямар ч path сургалтад ирвэл |
| `assert_no_golden_rows(rows, manifest)` | golden мөр CURATED-TRAIN-д **агуулгаараа** орвол |

### 2.1 КАРАНТИН — `--allow-leak` (A3-4, 2026-08-28)

«БҮХ дамжуулга ЗОГСОНО» нь ЗӨВ анхдагч, гэвч ГАНЦ зам байж болохгүй.
GOLDEN-EVAL-ын **83 мөрийн 79 нь ЖИРИЙН хэрэглэгчийн өгүүлбэр**
(«хуудсуудаа харул даа», `intents` + `adversarial`) тул нэг ажилтан Revit
дотор ижил өгүүлбэр бичихэд тэр мөр `production.json`-д орж, **ӨДӨР ТУТМЫН
гогцоо БҮХЭЛДЭЭ зогсоно** — эвдэрсэн зүйл нь ердөө НЭГ МӨР байхад.

```bash
$PY ../training/pull_and_retrain.py --offline --allow-leak
```

| Юу | Хатуу зам (анхдагч) | `--allow-leak` |
|---|---|---|
| golden мөр өгөгдөлд орсон | БҮХ дамжуулга ЗОГСОНО | зөрчсөн **мөр** карантинд, үлдсэнээр үргэлжилнэ |
| golden **ЗАМ** сургалтад дамжсан | ЗОГСОНО | **ЗОГСОНО** (дуудагчийн алдаа, өгөгдлийнх биш) |
| манифест эвдэрсэн | ЗОГСОНО | **ЗОГСОНО** (батламж өөрөө утгагүй болсон) |

- Хасалт нь **ЦЭВЭРЛЭСЭН ХУУЛБАР** дээр хийгддэг (түр хавтас, процесс
  дуусахад устдаг) — `training/data/`-ийн эх файл **ХӨНДӨГДӨХГҮЙ**.
- **«NO SILENT CAPS»** — хассан мөрийн тоо файл тус бүрээр БА нийтээр
  ЗААВАЛ хэвлэгдэнэ, эхний 12 өгүүлбэр нь бүтнээрээ; бүрэн жагсаалт нь
  `training/quarantine.report.json`-д үлдэнэ.  Хасалт чимээгүй болмогцоо
  энэ горим нь «алдагдлыг үл тоомсорлох» болж хувирна.
- Манифестын мета дахь `sha256` нь **цэвэрлэсэн хуулбарын** хэш болж
  солигдоно (эх хэш нь `source_sha256`-д үлдэнэ), `note`-д
  `quarantined=N` бичигдэнэ — эс бөгөөс `report.json`-ы provenance худал
  болно.
- **Карантин нь ЗАСВАР БИШ, ХОЙШЛУУЛАЛТ.**  Golden талыг нь `freeze.py`
  -аар СОЛИХ ёстой хэвээр; эс бөгөөс тэр өгүүлбэрүүд ХЭЗЭЭ Ч сурагдахгүй.

## 3. МӨРИЙН ТАНИХ ТЭМДЭГ — `row_id`

```python
from train_intent import row_id      # 1B-4-ийн тодорхойлолт
row_id(text, intent) == sha256(preprocess(text) + "\x00" + intent)[:16]
```

⚠️ **Түлхүүр нь ТҮҮХИЙ ТЕКСТ БИШ, ЭВХСЭН текст + санаа.**
`train_intent.clean_records()` нь давхардлыг яг тэр хосоор хасдаг тул
«ЦБУ-05 ыг 70 хувь болголоо» ба «cbu 05 ig 70 huv bolgoloo» нь загварын
хувьд **ЯГ НЭГ мөр**.  Түүхий текстээр батламж бичсэн бол golden мөрийг
латинаар хөрвүүлээд сургалтад чөлөөтэй оруулж, батламжийг тойрч болох байв.

**Хэмжсэн (2026-08-28):** санаатай эвдэлтийн туршилтад кирилл ба латин
хоёр хувилбар **хоёулаа** `eb7bf88397aea24d` гэсэн НЭГ id авч, батламж
хоёуланг нь барив.

⚠️ `train_intent.PREPROCESS_CONTRACT` (одоо `fold-v1`) өөрчлөгдвөл **БҮХ
`row_id` хүчингүй**.  Тэр үед `freeze.py recontract`-ыг **ТУСДАА commit**-оор
ажиллуул: golden-ийн АГУУЛГА өөрчлөгдөөгүй, зөвхөн ТАНИХ ТЭМДЭГ өөрчлөгдсөн
гэдэг нь diff дээр ил байх ёстой.

### ⚠️ A3-8 · GOLDEN-EVAL нь өнөөдөр БИЕ ДААСАН БИШ (ЗАСАГДААГҮЙ)

83 golden мөрийн **79 нь `author: check_behavior.py`** — өөрөөр хэлбэл
тэдгээр өгүүлбэрийг зан төлөвийн шалгалт бичсэн хүн зохиосон.  Тиймээс
`check_behavior.py` ба `run_golden.py --kind intent` хоёр нь **ХАРААТ БУС
хоёр дохио БИШ**: нэг л багцыг хоёр өөр harness-аар уншиж байна.  Хоёулаа
ногоон байх нь «загвар ерөнхийлж байна» гэсэн үг БИШ, «энэ нэг багцыг
даван гарч байна» гэсэн үг.

Б3 (2026-08-28) нь **ХУУЛБАРЫГ** арилгасан (`check_behavior.PROBES` одоо
энэ файлыг УНШИНА, өөрийн литерал байхгүй) — тэр нь ХОЁР хуулбар зөрөх
эрсдэлийг зогсоосон ч **нэг дохиог хоёр болгодоггүй**.

Засвар нь ӨӨР ГАРААС гарсан ШИНЭ мөр зохиох явдал (жишээ нь бодит
`assistant_log` бичлэгээс `nominate.py`-аар нэр дэвшүүлж, ХҮН баталах).
Энэ нь **ӨГӨГДЛИЙН шийдвэр, инженерийн биш** тул кодын сессэд хийхгүй.

### ⚠️ ХООСОН ХУВААРЬ = ХАТУУ БЛОК

```
python run_golden.py --kind bim     # → ❌ БЛОКЛОВ: bim   (exit 2)
```

Хоосныг **алгасахгүй**.  Хоосон = «бид хараахан хэмжээгүй», алгасалт =
«хэмжих шаардлагагүй».  Хоёр өөр мэдэгдэл; систем эхнийхийг хэлэх ёстой.
Эс тэгвээс Track C-ийн эхний загвар «BIM-ийг ойлгодог» гэж мэдэгдэхэд
түүнийг **няцаах тоо байхгүй** болно.

Өнөөдөр: `--kind intent` **НИЙТЛЭГДЭЖ ЧАДНА**, `--kind bim` / `--kind rules`
**ЧАДАХГҮЙ**.  Энэ бол алдаа биш, зорилго.

## 5. Регресс нэмэх журам (ЦОРЫН ГАНЦ зам)

```
..\server\.venv\Scripts\python.exe freeze.py add-regression ^
    --text "ирцээ тэмдэглэх хуудас хаана байдаг вэ" --intent unknown ^
    --incident HN-1 --first-seen 2026-08-25 --was "submit_progress@0.58" ^
    --why "«бүртгүүл» нь submit_progress-ийн n-gram-д дийлдэг" ^
    --author "<нэр>"
```

`freeze.py` нь: `row_id` тооцно → CURATED-TRAIN-тэй тулгана (давхцвал
**ТАТГАЛЗАНА**) → `regressions.json`-д нэмнэ → `manifest.exclude_row_ids`
шинэчилнэ → SHA-256 дахин тооцно.

⚠️ **МӨР ХАСАХ ДЭД КОМАНД БАЙХГҮЙ.**  Санаатай.  Хасах ёстой бол ГАРААР
засаад PR-т ЯАГААД гэдгийг бич — хүний хяналт нь механизм.

⚠️ **Регрессийн мөр нь `hard-negatives.json`-ы ХУУЛБАР БАЙЖ БОЛОХГҮЙ.**
Тэр 46 мөр бол **ЗАСВАР**, сургалтад ордог; хуулбарлавал тест нь загвар
**цээжилсэн эсэхийг** хэмжинэ.  Мөр бүр ижил уналтын **утгыг** барих ба
`preprocess()`-ээр **ӨӨР эвхсэн түлхүүр** өгөх ёстой (`freeze.py` үүнийг
өөрөө шалгаж татгалзана).

## 7. Хилийн зурвас — `nominate.py`

**Зангуу нь `revit-mcp/addin/IntentRouter.cs:81`-ийн `MinConfidence = 0.45`.**
`app_settings['assistant.min_confidence']` **БИШ** — тэр мөрийг репо даяар
**ХЭН Ч УНШДАГГҮЙ** (migration `0195:154-156` өөрөө ингэж бичсэн), өөрчилвөл
**ЮУ Ч болохгүй**.  `nominate.py` нь C# файлаас бодит утгыг уншиж тулгадаг —
зөрвөл шууд унана.

`BAND = 0.07` → **[0.38, 0.52]**.  Үндэслэл: `IntentRouter.cs:52-64`-ийн
2392 мөрийн хэмжилтэд 0.40 ↔ 0.55 хооронд «үйлдэл хийсэн» 93.1% → 88.2%
болж хөдөлдөг, өөрөөр хэлбэл **шийдвэр яг тэр зурваст хөдөлгөөнтэй**.  Мөн
дөрвөн түүхэн уналтын **гурав** (0.58 · 0.41 · 0.38) энэ зурваст эсвэл
хаяанд нь байв.

⚠️ **Нэр дэвшүүлэлт автомат, БАТЛАХ нь автомат БИШ.**  Автомат оруулбал
загвар өөрийн эргэлзээгээ өөрөө шалгуур болгож, гогцоо хаагдана.

файл сургалтын датасет мэт харагддаг байв.

### ⚠️ «45 vs 46» — хоёр өөр тоо, зөрчил БИШ

* **Түүхий мөр** = файлын `rows` массивын урт.  `hard-negatives.json` = **46**.
* **Хувь нэмэр оруулсан мөр** = эвхэлтээр давхардал хассаны дараах.  = **45**
  («одоо хэдэн цаг болж байна» кирилл ба латин хоёр бичлэгээр орсон, хоёулаа
  `preprocess()`-ийн дараа НЭГ мөр).

Мөн `unique_folded_rows` = **2402** нь бүх файлын **давхардал хассан** нийлбэр;
түүхий мөрийн нийлбэр (**2532**) -тэй **хэзээ ч** таарахгүй.  Тоо зөрөхөд
эхлээд **аль тоог** хэлж байгааг тодруул.
