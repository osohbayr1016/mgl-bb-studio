## 1. ХӨНДЛӨН ДАВХЦАЛ

### 1.1 [BLOCKER] `бүгдийг харуул` — reset_view vs list_sheets
Давхцаж буй мөрүүд:
- reset_view / terse: `"бүгдийг харуул"`
- reset_view / latin: `"bugdiig haruul"`
- list_sheets / terse: `"бүх хуудас"`, `"жагсаа"`; cyrillic: `"хуудсуудаа бүгдийг нь гарга"`

reset_view-ийн өөрийнх нь notes энэ мөрийг «хамгийн эрсдэлтэй» гэж хүлээн зөвшөөрсөн байна — тэгээд яг тэр мөрийг сургалтын жишээ болгож үлдээсэн нь алдаа.

**ШИЙД:** reset_view-ээс `"бүгдийг харуул"` болон `"bugdiig haruul"`-ыг **ХАС**. Оронд нь объекттой хэлбэрээр солино:
- `"бүх элементийг харуул"` (terse, slot "")
- `"buh elementee haruul"` (latin, slot "")

reset_view-д объект («элемент/загвар/model/тусгаарлалт/isolate») агуулаагүй ямар ч мөр байж болохгүй гэсэн дүрмийг тогтоо.

### 1.2 [BLOCKER] Объектгүй цуцлалт — reset_view vs unknown-ий бодлого зөрчилдөж байна
- reset_view / terse: `"цуцал"`, `"буцаа"`, `"болиул"`
- unknown / question: `"болих уу"`
- unknown / notes: «"болих уу", "буцаа" маягийн объектгүй мөрүүд ... **объект тодорхойгүй бол unknown**»

Өгөгдөл нь өөрийнхөө бодлоготой зөрчилдөж байна: `болиул` = reset_view, `болих уу` = unknown, зөвхөн төгсгөлийн нөхцлөөр ялгарч байна. Ангилагч энэ ялгааг сурахгүй.

**ШИЙД:** нэг бодлого сонго. Зөвлөж буй нь:
- reset_view-ээс `"болиул"`-ыг **ХАС** (`"тусгаарлалт болиул"` болгож засах).
- `"цуцал"`, `"буцаа"` хоёрыг reset_view-д **ҮЛДЭЭ** (Revit панель дотор эдгээр нь бараг үргэлж isolate цуцлах), гэхдээ unknown-ий notes-оос «"буцаа" ... unknown» гэсэн өгүүлбэрийг устга.
- unknown-оос `"болих уу"`-г **ХАС** (`"болиул"`-тай ялгагдахгүй).

### 1.3 [MAJOR] help ↔ list_sheets
- help / codeswitch: `"list хийж болох бүх зүйлсээ харуул"` — `list` + `бүх` + `харуул` гурван токен нь list_sheets-ийн `"sheet list"`, `"бүх хуудсаа жагсаа"`-тай шууд өрсөлдөнө.
- help / codeswitch: `"sheet үүд дээр юу юу хийж чадах вэ"` — list_sheets-д `"хуудсууд нь юу юу байна"`, `"ямар ямар хуудас байгааг харуул"` байна. `sheet` + `юу юу` хослол хоёуланд нь.

**ШИЙД:** help-ээс энэ хоёр мөрийг **ХАС**, оронд нь:
- `"чи ямар үйлдэл дэмждэгээ жагсаа"` (codeswitch → `"дэмждэг action уудаа жагсаа"`)
- `"хуудсан дээр чи юу хийж чадах вэ"`-г бүү нэм — list_sheets-тай мөн адил давхцана.

### 1.4 [MAJOR] set_baseline ↔ submit_progress
- set_baseline / cyrillic: `"өнөөдрийн ажлаа эндээс тоолуулъя"`

**ШИЙД:** set_baseline-ийн мөрийг `"өнөөдрийн ажлаа эндээс тоолуулъя, суурь ав"` болгож **ЗАС** (эсвэл бүрэн хас — polite хэсэгт `"Өнөөдрийн ажлаа эндээс тоолуулахын тулд эхлэлийг тэмдэглэж өгнө үү"` гэсэн тодорхой хувилбар аль хэдийн байна).

### 6.1 [OK] Дутуу бөглөсөн slot байхгүй

### 6.2 [BLOCKER] slot-ын БИЧИГ нормчлогдоогүй — нэг хуудсыг 2 өөр утгаар заасан
| Кирилл slot | Латин slot | Аль аль нь өгөгдөлд байна |
|---|---|---|
| `БА-01` | `BA-01` | isolate, submit, progress_status, reset_view |
| `ХАС-12` | `HAS-12` | isolate |
| `ЦБУ-05` | `TSBU-05` | isolate |
| `ЦАХ-07` | `TSAH-07` | isolate |
| `ББ-21` / `ББ-05` | `BB-21` / `BB-05` | isolate |
| `АУ-04` | `AU-04` | isolate |
| `ИЗ-06` | `IZ-06` | isolate |
| `ЭЗ-02` | `EZ-02` | isolate |

Ойролцоогоор **45 кирилл slot vs 22 латин slot**. Загвар нэг физик хуудсыг хоёр өөр танигчаар сурна → Revit руу дамжуулахад `ХАС-12` нь `HAS-12` нэртэй ViewSheet-ийг олохгүй.

**ШИЙД:** slot-ыг **нормчлогдсон канон хэлбэрээр** хадгал (текстээс шууд хуулж авахгүй). Ямар канон болохыг Revit дэх бодит `ViewSheet.SheetNumber` жагсаалтаас тогтоо, дараа нь:
- бүх латин бичлэгтэй өгүүлбэрийн slot-ыг канон хэлбэр рүү бич (ж: `"BA-01 iig haruul"` → `slot: "БА-01"`, хэрэв канон нь кирилл бол),
- эсвэл эсрэгээр.
- Нэмэлтээр `slot_surface` (текстээс хуулсан) ба `slot` (нормчлогдсон) гэсэн ХОЁР талбар болго — тэгвэл галиглалт нь сургалтын дохио болно.

### 6.3 [MAJOR] slot-гүй санаанд slot бөглөсөн — тодорхойгүй бодлого
- **help / codeswitch:** `"БА-01 дээр чи ямар үйлдэл support хийдэг вэ"` → `slot: "БА-01"`. `help` нь хуудас хүлээж авдаггүй.
- **unknown:** `"БА-01 д хаалга нэмээд өгөөч"`, `"HAS-05 ийн агаар сэлгэлтийн тооцоог шалгаад өгөөч"`, `"БА-01 ийг pdf болгож хэвлэ"` → бүгд бөглөгдсөн.
- **reset_view:** 5 мөр бөглөгдсөн ч `reset_isolation` хэрэгсэл параметр авдаггүй.

**ШИЙД:** slot-ын семантикийг **бичгээр тогтоо**. Зөвлөж буй: «slot = текстэд дурдагдсан бүтэн хуудасны код, хэрэгсэл түүнийг ашигладаг эсэхээс үл хамааран». Хэрэв энэ бодлого бол:
- 6.3-ын бүх мөр **ЗӨВ**, зөвхөн help-ийн мөрийг хиймэл учраас хас (3.6).
- Хэрэв эсрэг бодлого («зөвхөн хэрэгсэл ашигладаг бол») сонговол help/unknown/reset_view-ийн 9 slot-ыг бүгдийг нь `""` болго.

Одоо аль нь ч баримтжаагүй тул тэмдэглэгээ хийж буй хүн бүр өөрөөр таамаглана.

### 6.5 [MAJOR] Баталгаажаагүй шифр — 4 угтвар сэжигтэй
