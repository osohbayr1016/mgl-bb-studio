MGL Revit нэмэлт __VERSION__ — СУУЛГАХ / ШИНЭЧЛЭХ
================================================

ӨРӨӨНИЙ ПЛАН — QA / ТУРШИЛТЫН АЖИЛЛАГАА (зөвхөн QA багцад)
  • MGL → Зураг → «Олон өрөөний план»: Revit Floor Plan дээр 1–24 ТУСДАА тэгш өнцөгт Floor сонгоно.
  • Нэгж бүрийн орох хана, унтлагын өрөөний тоог сонгосны дараа local Python хөдөлгүүр
    хувилбаруудаа үүсгэнэ. Нэгж тус бүр дээр сонголт хийж байж Хэрэгжүүлэх дарна.
  • QA installer-д RoomPlan/Python/roomplan_cli.exe байвал Python 3 тусад нь суулгахгүй;
    .exe байхгүй бол Python 3-ийн суулгац шаардлагатай. Зөвхөн local SQLite тэмдэглэлтэй.
  • Door, Furniture, Kitchen Casework, Sanitary Family Type-ууд урьдчилан Revit project-д
    ачаалсан байх ёстой. Тохирохгүй бол систем бүх batch-ийн transaction-ийг буцаана.
  • ХАМАГ ЗҮЙЛ НОРМ ХАНГАСАН гэсэн баталгаа биш; Монголын БНбД, MNS, хаалганы
    нээгдэх чиглэл, гэрэлтүүлэг/MEP-г архитектор хүн заавал шалгах шаардлагатай.
  • Энэ нь REALTIME биш: modal preview нээлттэй үед Revit моделийг өөрчлөх боломжгүй.
  • QA багцын үр дүнг бодит Revit дээр баталгаажуулаагүй байхад компани даяар бүү тараа.

Энэ нэг багцад MGL Revit нэмэлтийн БҮХ хэрэгсэл орсон (Revit __YEARS__).  MGL таб дээрх самбарууд (1.37.0-оос САЛБАРААР):
  • Ажил — «Миний ажил» (таск, явц/тайлан, ажлын цаг; Revit 2025+), «AI туслах», «Хэрэгсэл хайх», «Ажилтай холбох»
  САЛБАРЫН САМБАР — ажилтан зөвхөн ӨӨРИЙН салбарынхыг харна (ERP-ийн багаар; Тохиргооноос өөрчилнө):
  • Архитектур (БА, Эскиз, Гадна тохижилт) — «Ханын дэлгээс»
  • Интерьер — «Ханын дэлгээс» (БА-гийнхаас тусдаа товч)
  • Бүтээц (ББ) — «Төгсгөлийн тэмдэг», «Хуулбарлаж зурах», «Тэмдэглэгээ шинэчлэх», «Захын, голын арматур»,
    «Ширхэг харуулах», «Арматурын урт», «Түүвэр хувилах», «Түүвэр шинэчлэх»
  • Инженерийн шугам (ХАС, ЦБУ, Цахилгаан, ХД, АУ) — одоогоор тусгай хэрэгсэлгүй (самбар гарахгүй)
  НИЙТЛЭГ САМБАР — бүх хүнд:
  • Зураг — «Хуудас дугаарлах», «Зураг хувилах», «Хэмжээс, тэмдэглэгээ», «Элемент хуулах», «Хуудас үүсгэх»,
    «Тэнхлэг, түвшин»
  • Шалгалт (зөвхөн Revit 2025+) — «Элемент тоолох», «Давхцал шалгах», «Өөрчлөлтийн нөлөө», «Өөрчлөхөөс өмнө»
  • Экспорт — «Файл гаргах» (PDF/DWG/IFC хавтсанд; Revit 2025+), «ERP-д илгээх» цэс:
    Тоо хэмжээ илгээх · PDF илгээх · Түүвэр илгээх
  • Сан ба тохиргоо — «Family сан» (Revit 2025+), «Бүртгэл, эрх» (компанийн бүртгэлээр нэвтрэх, энэ компьютерын
    лиценз + төхөөрөмжийн түлхүүр), «Тохиргоо»
  «Хэрэгсэл хайх» каталог нуугдсан самбарын хэрэгслийг ч олж нээнэ.
(Энэ жагсаалтыг хувилбар бүрт installer\bundle-README.txt-д шинэчилнэ.)

1.37.0 — ТУУЗАН ЦЭС САЛБАРААР + «ХАНЫН ДЭЛГЭЭС» ӨРӨӨ СОНГОХ ШИНЭЧЛЭЛ:
  • MGL таб нэг хэвээр, харин хэрэгслүүд салбараар бүлэглэгдсэн: Архитектур · Интерьер · Бүтээц · Инженерийн шугам
    самбарууд + бүх хүнд харагдах нийтлэг самбарууд.  Ажилтан нийтлэг самбарууд + ӨӨРИЙН салбарын самбарыг харна.
  • Салбар нь ERP дээрх таны багаас автоматаар (BA/EZ/GT → Архитектур, BB → Бүтээц, IZ → Интерьер, инженерийн багууд →
    Инженерийн шугам; Менежмент, баг тодорхойгүй, нэвтрээгүй бол БҮХ хэрэгсэл).  Тохиргоо → «3. Туузан цэсэнд харагдах
    хэрэгсэл»: Миний ERP-ийн багаар · Өөрөө сонгох · Бүх хэрэгсэл — сонгомогц шууд хэрэгжинэ, Revit дахин асаах хэрэггүй.
  • «Ханын дэлгээс» Архитектур ба Интерьер самбарт тус бүр товчтой (дараа нь салбар бүрт өөр загвартай болно).
  • «Ханын дэлгээс»: «Өрөө, хана сонгох» → план эсвэл ХУУДСАН дээр өрөөний дотор (Room Reference «X» тэмдэг дээр, хоосон хэсэгт
    эсвэл tag дээр) дарна → Esc = дуусгах.  Интерьерийн файлд өрөө нь архитектурын LINK-д (host-д 0 өрөө) байсан ч олно.
    Хуудсан дээр viewport идэвхжүүлэх шаардлагагүй.  Дахин дарвал сонголтоос хасна.  Хуучин аргаар сонгох нь «Элемент сонгох».
  • «Ханын дэлгээс» засвар: доод давхрын өрөөний дэлгээст дээд давхрын шал, тавилга орж ирдэг байсныг засав (хүрээ дээд
    давхрын түвшинд хүрээд зогсоно; давхрын хэмжээс, түвшний тэмдэг хэвээр).  Link буулгасан (unloaded) бол сонголтод өрөө
    олдохгүй байх шалтгааныг link-ийн нэрээр хэлнэ.
  • 1.36.0 хүртэлх бүх өөрчлөлт энэ багцад орсон.

1.36.0 — «ХЭМЖЭЭС, ТЭМДЭГЛЭГЭЭ»: НЭГ «БАЙРЛАЛ» БҮХ ХЭМЖЭЭСЭД:
  • «Байрлал» (тал + «Ханаас эхний гинж» + «гинж хооронд») одоо хэрэгслийн БҮХ хэмжээсэд нэг: ерөнхий хэмжээс, дам нуруу/баганын
    огтлолын хомутын ба гадна гинж, дэлгээсийн хэмжээс (MRA, давхцал, тэнхлэг/түвшний гинж), хана-хучилтын ерөнхий хэмжээс.
  • Цонхонд «Байрлал» гурван газар харагдана — аль нэгийг нь засахад бусад нь шууд дагана.
  • Баганын дэлгээс: «Зөвхөн зүүн ба доод талд» = хэмжээс баганын ЗҮҮН талд, «Зөвхөн баруун ба доод талд» (ба «4 талд») = БАРУУН талд.
  • Дэлгээс: хэмжээсийн шугам гишүүнээс «эхний гинж»-ийн зайнаас ойр тавигдахгүй (шошго түүнээс цааш бол шошгоны ард).
    Гараар заасан «хомутын MRA хүртэл» зай хэвээр давамгайлна.

1.35.0 — «ХЭМЖЭЭС, ТЭМДЭГЛЭГЭЭ»: «БАЙРЛАЛ»-Д «ЗӨВХӨН БАРУУН БА ДООД ТАЛД»:
  • «Байрлал» одоо гурван сонголттой: 4 талд · Зөвхөн зүүн ба доод талд · Зөвхөн баруун ба доод талд.
  • «Баруун ба доод» = хэвтээ хэмжээс доор, босоо хэмжээс (түвшин, тэнхлэг, огтлолын өндөр) БАРУУН талд.
  • «Бас ерөнхий хэмжээс» (план, зүсэлт, фасад), огтлолын хомутын/гадна гинж, «Хана, хучилт»-ын ерөнхий хэмжээс гурвуулаа.
  • Өмнө хадгалсан тохиргоо хэвээр (зүүн ба доод).

1.34.0 — «ХЭМЖЭЭС, ТЭМДЭГЛЭГЭЭ»: «БАЙРЛАЛ» БҮХ ХЭМЖЭЭСЭД ИЖИЛ:
  • «Бас ерөнхий хэмжээс»-ийн «Байрлал» (4 талд / Зөвхөн зүүн ба доод талд + эхний гинж, гинж хооронд) одоо
    «Баганын арматурын хэмжээс» → огтлол (хомутын «30 | 240 | 30» ба гадна гинж) болон «Хана, хучилт» → ерөнхий хэмжээсэд ч ижил.
  • Огтлол: «4 талд» = хэвтээ хэмжээс дээр ба доор, босоо хэмжээс зүүн ба баруун; «Зөвхөн зүүн ба доод» = доор ба зүүн.
    Эхний гинж = дам нуруу/баганын ирмэгээс, гинж хооронд = хомутын гинжээс гадна гинж хүртэл.  1.33.0-ийн
    «Дээр/Доор, Зүүн/Баруун» сонголтыг энэ орлосон.
  • Хана, хучилт: ерөнхий хэмжээс ирмэгээс «эхний гинж»-ийн зайд, тэр талд MRT/шошго цухуйвал тэдгээрээс «гинж хооронд» цааш
    (аль хэдийн байсан MRT-г ч тооцно).  «Эсрэг талд тавих» одоо зөвхөн MRT-д.
  • 1.33.0-ийн өөрчлөлт энэ багцад орсон.

1.33.0 — «ХЭМЖЭЭС, ТЭМДЭГЛЭГЭЭ» засвар:
  • «Хана, хучилт»: multi rebar tag (MRT) одоо «Middle» / «First/Last» дүрслэлтэй (харагдацад 1–2 ширхэг л зурагдсан)
    арматурын олонлог дээр ч тавигдана — өмнө нь ийм олонлогийг чимээгүй алгасдаг байв.  Хэмжээсийн шугам олонлогийг
    бүхэлд нь хамарна.
  • Нэг арматурт НЭГ multi rebar tag: аль хэдийн MRT-тай арматурт давхар тавихгүй; давхардсан MRT байвал илүүг нь устгаж
    эртнийхийг үлдээнэ.  Тайланд «N олонлог аль хэдийн MRA-тай», «давхардсан MRA N устгав» гэж гарна.
  • «Дам нурууны арматурын хэмжээс» → огтлол: хэмжээсийг аль талд тавих — хэвтээг Дээр/Доор, босоог Зүүн/Баруун
    (хомутын гинж ба гадна гинж хоёулаа; шошго тэдгээрээс цааш).
  • 1.32.0-ийн өөрчлөлт энэ багцад орсон.

1.32.0 — ШИНЭ «АРМАТУРЫН УРТ» (MGL таб → Арматур):
  • Арматуруудаа олноор сонгоод (Finish/Enter) хэмжээс тавих байрлал дээр хулганаар дарна — сонгосон арматуруудын
    төгсгөлүүдээр ҮРГЭЛЖИЛСЭН хэмжээс тавигдана: ганц арматурт урт нь, давхцалтайд «урт | давхцал | урт».
  • Багана, дам нуруу, хана, хучилтын арматур; план, огтлол, дэлгээс, detail харагдац.  Өөр чиглэлийн арматурт тусдаа хэмжээс.
  • Хэмжээсийн төрөл = таны одоо хэрэглэж буй (Annotate → Aligned-ийн сүүлд сонгосон) төрөл.
  • Давтан ажиллана (Esc = дуусгах); тавилт бүр нэг Ctrl+Z.  Утгыг арматурын бодит төгсгөлтэй тулгаж, зөрвөл тавихгүй.
  • 1.31.0-ийн өөрчлөлт энэ багцад орсон.

1.31.0 — «ХЭМЖЭЭС, ТЭМДЭГЛЭГЭЭ» → «Дам нурууны арматурын хэмжээс»:
  • Дам нуруу/баганын дэлгээс дээр давхцалтай ажлын арматурын «A-ийн урт | давхцал | B-ийн урт» үргэлжилсэн (гинжин)
    хэмжээс ХАСАГДСАН — чагт алга, ямар ч тохиргоонд тавигдахгүй.  Давхцлын өөрийн хэмжээс («500»), хомутын MRA,
    тэнхлэг/түвшний гинж, «Хана, хучилт» табын үргэлжилсэн хэмжээс хэвээр.

1.30.0 — «ХАНЫН ДЭЛГЭЭС»: ОФФИСЫН 13 ЖИШИГ ХУУДАСТАЙ (ИЗД1_A2_39…51) ТУЛГАСАН (Revit 2024 дээр бодит төсөлд туршсан):
  • Хуудасны дугаар, нэр төслийнхөөрөө: «ИЗД1_A2_97 — 218 АЦӨ /ЭМЭГТЭЙ/ ХАНЫН ДЭЛГЭЭС /A BLOCK 2-Р ДАВХАР/ /218A-H/».
  • Үсэг жишиг шиг: A — баруун, B — хойд, C — зүүн, D — урд хана, бусад нь E, F …; түлхүүр план оффисынх шиг 90° эргэсэн.
  • Босоо хэмжээс жишиг шиг: «80 · 50 · 2670 · 1200» (түвшин → шал → гол тааз → дээд давхар) + «4000»; шал, таазны түвшин (0,08 · 2,80)
    бүх дэлгээст; хэвтээ нийт урт бүх дэлгээст (өмнө нь link-ийн хананд тавигддаггүй байсан).
  • Нэг өрөөний дэлгээсүүд нэг хуудсанд багтах нь олширсон (зай, хүрээ жишиг шиг нягт); том өрөөнд 3D зургийг шаардлагатай бол доош нь.
  • Утгагүй жижиг дэлгээсгүй: 20 мм-ийн хонхор, хаалт хавтангийн үзүүр, цухуйсан хайрцгийн урд нүүр — тайланд шалтгаантай.
  • Таазны гэрэлд шошго, хэмжээсгүй; кабинкын хаалганд шошго; шошго давхцвал зөөнө; 3–30 мм-ийн жижиг хэмжээсгүй.

1.29.0 — «ХЭМЖЭЭС, ТЭМДЭГЛЭГЭЭ»: ИНЖЕНЕРИЙН САНАЛ R-1 + ШИНЭ «ТЭНХЛЭГ, ТҮВШИН» (бодит Revit 2027 дээр туршсан):
  • «Түргэн» таб: «Багана, дам нурууны хэмжээ — тэнхлэг, хана, хучилттай уялдуулах» чагт.  Огтлол дээр хомутын хэмжээсийн
    гадна нэг гинж: дам нурууны нүүр | тэнхлэг | нүүр («150 | 150»), хучилтын дээд/доод нүүр | дам нурууны доод («170 | 330»),
    хажуугийн ханын нүүр.  Багана, планд ч мөн («200 | 200»).
  • Таб «Арматур (огтлол, дэлгээс)» → «Дам нурууны арматурын хэмжээс».
  • Multi Rebar Tag-ийн элементээс байх зай одоо ЯГ таны оруулснаар (бусад мөр түүний гадна шилжинэ).
  • Зөрүүлэгтэй торны ҮРГЭЛЖИЛСЭН хэмжээс (чагт): торны төгсгөл бүрийг мэдэрч нэг гинжээр «2600 | 500 | 3200 | 500 | …».
  • «Хана, хучилт» таб: Multi Rebar Tag, Tag (төрөл сонгоно), Ерөнхий хэмжээс (элементээс зай), Зөрүүлгийн үргэлжилсэн хэмжээс —
    тус бүр тусдаа чагт.
  • ШИНЭ товч MGL таб → Зураг → «Тэнхлэг, түвшин»: огтлол/фасад/detail харагдацад тэнхлэгийн доод (дугуйтай) ба дээд үзүүр,
    түвшний зүүн ба баруун үзүүрийг crop хүрээнээс оруулсан мм-ийн зайд тавина.  Зөвхөн ТЭР харагдацад; нэг Ctrl+Z-ээр буцна.
  • Анхаар: хучилтын харагдац «Middle» горимд (1 тор л харагдана) Multi Rebar Tag, зөрүүлгийн гинж тавигдахгүй — «All» болго.
  • 1.28.0 хүртэлх бүх зүйл (Ханын дэлгээс г.м.) энэ багцад орсон.

1.28.0 — «ХАНЫН ДЭЛГЭЭС»: ИНТЕРЬЕРИЙН ЖИШИГ ХУУДАСТАЙ ТУЛГАСАН (Revit 2024 дээр бодит төсөлд туршсан):
  • Интерьерийн файлд өрөө архитектурын LINK-д байдаг — планаас өрөөний tag (эсвэл бүх планыг) сонгоход дэлгээс гарна.
  • Өнгөлгөөний тэмдэглэл элементийн төрлийн Keynote утгаар: «ЦАГААН ЭМУЛЬС», «СААРАЛ ДААВУУН ХУЛСАН ХАВТАН» дэлгээсийн дээр,
    «МЕТАЛЛ ХАР ШАЛНЫ ХҮРЭЭ» доор (жишиг хуудас шиг).

  • ШИНЭ «Хэрэгсэл хайх» (Ажил самбар): бүх хэрэгслийг нэрээр (хуучин нэр, латинаар ч) хайж, заавар уншиж, «Нээх»-ээр
    шууд ажиллуулна; хэрэгсэл идэвхгүй бол ЯАГААД гэдгийг хэлнэ.
  • Бүх цонх (~35) нэг хэв маягтай; Revit-ийн Гэрэл / Харанхуй загварыг дагана; цонх дэлгэцээс хальж гарахгүй.
  • ERP-тэй холбогдож байх үед Revit «Not Responding» болж гацахын оронд «Сервертэй холбогдож байна» цонх гарна.
  • «Ажилтай холбох»: «Холбоос хадгалах», батлагдсан/алгассан тоо, хайлт, хадгалаагүй өөрчлөлттэй хаахад сануулна.
  • «Хуудас үүсгэх»: алдаа талбар дээрээ, давхардсан дугаарын тоо.
  • ⚠ Quick Access Toolbar-т нэмсэн эсвэл товчлуур (shortcut) оноосон MGL товч самбар солигдсон бол дахин нэмэх
    шаардлагатай байж болно.
  • Туршилт: ТУРШИХ-UI-шинэчлэл.txt.

1.13.0 — ОГТЛОЛЫН ТЭМДЭГЛЭГЭЭ: ЗАГВАР ХАРАГДАЦААС ХУУЛАХ (Revit дээр ХАРААХАН туршигдаагүй):
  • «Арматур» → «Огтлолын тэмдэглэгээ» цонхны дээд хэсэгт «Загвар харагдацаас хуулах»: гараар зурсан төстэй
    харагдацынхаа нэрийг хайж сонгоод «Загвараас хуулах» дарахад түүний хэмжээс, арматурын tag, текст энэ
    харагдац дээр шууд нэмэгдэнэ.  Шинэ харагдац үүсэхгүй, дараа нь гараар засна.  Таны гараар тавьсан зүйл
    устахгүй; дахин дарвал давхар үүсэхгүй.
  • 1.12.1-ийн «Төгсгөлийн тэмдэг» дараалан дарах горим ч орсон (доор).
  • Туршилт: ТУРШИХ-Арматур.txt («1б.») + docs\REINFORCEMENT.md §15.4.

1.12.1 — «ТӨГСГӨЛИЙН ТЭМДЭГ» ДАРААЛАН ДАРАХ ГОРИМ (Revit дээр ХАРААХАН туршигдаагүй):
  • Тохиргооны цонх НЭГ удаа → арматур бүр дээр дарах бүрт тэмдэг шууд тавигдана → дахин дар … → Esc = дуусгах.
    Дахин сонгох шаардлагагүй.  Явц Revit-ийн доод status bar-т («Тавьсан: N · Сүүлийнх: …»).
  • Ctrl+Z бүр СҮҮЛД дарсан арматурын тэмдгийг буцаана.  Урьдчилан сонгосон арматур байвал хуучин шигээ нэг дор.
  • Туршилт: ТУРШИХ-Арматур.txt («2. АРМАТУРЫН ТӨГСГӨЛИЙН ТЭМДЭГ» — 0-р алхам) + docs\REINFORCEMENT.md §14.

1.12.0 — АРМАТУРЫН ХЭРЭГСЛИЙН ИНЖЕНЕРИЙН САНАЛЫН ЗАСВАР (Revit дээр ХАРААХАН туршигдаагүй):
  • «Огтлол»: хуурамч (үл үзэгдэх) лавлагаа шугам ХЭЗЭЭ Ч үүсэхгүй.  Хэмжээс тэнхлэг бүрт НЭГ гинж
    (нүүр → хомутын ирмэг → хомутын ирмэг → нүүр), арматурын бодит лавлагаатай.  Лавлагаа олдохгүй тал
    алгасагдаж «Арматурын хэмжээсийн лавлагаа олдсонгүй.» гэж мэдэгдэнэ.  Диалог харагдац + элементийг
    харуулна; шошгоны төрөл олдохгүй/нуугдсан бол «Үүсгэх» идэвхгүй болж шалтгаан гарна.
  • «Төгсгөлийн тэмдэг»: «Эхний ширхэг» горим; Эхлэл, Төгсгөлийн эргэлт ТУСДАА; тэмдгийн шууд хайлт.
  • «Түүвэр хувилах»: эх түүврийн шууд хайлт; үүсэх түүврийн нэрийн жишээ (нэрийн загвар «Нэмэлт»-д).
  • Туршилт: ТУРШИХ-Арматур.txt + docs\REINFORCEMENT.md §13.6.

1.11.1 — АРМАТУРЫН ХЭРЭГСЛИЙН АУДИТЫН ЗАСВАР (1.11.0-г шинэчилнэ; Revit дээр ХАРААХАН туршигдаагүй):
  • «Түүвэр»: Partition-ийг зөвхөн арматурын «Partition» параметрээс авна (Workset-ийн нэр Partition болж орохгүй);
    хоёр Partition нэг нэртэй болох (DN:1 / DN_1, DN-2 / dn-2) үед түүврийг хөндөхгүй; хуваагдсан эсвэл
    «хуудсаар шүүх» түүврийг «Солих» устгахгүй; синкийн устгал нэрсийг жагсаана.
  • «Төгсгөлийн тэмдэг»: цэг болж харагдах (end-on) арматурыг дахин ажиллуулахад давхар тавихгүй.
  • «Огтлол»: «Солих» нь шинэ хэмжээс/tag БҮРЭН үүсээгүй үед өмнөхийг устгахгүй; T/L хэлбэр, нээлттэй (U) хомутод
    буруу хэмжээс тавихгүй (алгасаж шалтгааныг хэлнэ); proxy шугамд таны гараар холбосон хэмжээс устахгүй.
  • Туршилт: ТУРШИХ-Арматур.txt + docs\REINFORCEMENT.md §12.5 (эхлээд S1–S5).

1.10.1 — КОМПАНИЙН БҮРТГЭЛЭЭРЭЭ НЭВТРЭХЭД Л АЖИЛЛАНА:
  • Ямар ч хэрэгслийн товч дарахад эхлээд «MGL нэвтрэлт» цонх гарна — MGL системийн нэр, нууц үгээ
    бичнэ.  Шинэчилсний дараа НЭГ УДАА нэвтэрнэ (энэ компьютерт төхөөрөмжийн түлхүүр бүртгэгдэнэ);
    дараа нь нууц үг асуухгүй, автоматаар шалгана.
  • Ажлын, гэрийн, зөөврийн — аль ч компьютер дээр ажиллана.  Admin-ы зөвшөөрөл ХЭРЭГГҮЙ.
  • Түлхүүр энэ компьютерт (боломжтой бол TPM чипэд) хадгалагдана — add-in-ийн файл, тохиргоог хуулж
    өөр компьютерт тавьсан ч АЖИЛЛАХГҮЙ (тэр компьютер дээр өөрийн бүртгэлээр нэвтэрнэ).
  • Интернэтгүй үед сүүлийн шалгалтаас хойш 12 цаг ажиллана (дараа нь интернэтэд холбогдоно).
  • Бүртгэл идэвхгүй болсон, эсвэл admin тухайн компьютерыг хаасан бол ажиллахгүй.

СУУЛГАХ (шинэ компьютер) ба ШИНЭЧЛЭХ (1.5, 1.6 гэх мэт хуучин хувилбартай) — АЛХАМ НЭГ:
  1. Энэ ZIP-ийг БҮРЭН задална (баруун товч → Extract All / Бүгдийг задлах).
     ⚠ ZIP дотроос нь шууд Install.bat дарж болохгүй — эхлээд задална.
  2. Задалсан хавтсанд байгаа "Install.bat" дээр давхар дарна.
  3. Суулгагч өөрөө:
       • энэ компьютерт суусан Revit (2024–2027) бүрийг олно;
       • хуучин MGL нэмэлт байвал (ямар ч аргаар суусан байсан) шинэ хувилбараар СОЛИНО;
       • байхгүй бол бүх файлыг ШИНЭЭР суулгана;
       • файл бүрийг хэшээр шалгана — гэмтэлтэй бол юу ч хөндөхгүй, хуучин нь хэвээр үлдэнэ.
     Эцэст нь «Revit 2027: 1.5.1 → __VERSION__ шинэчиллээ» гэх мэт тайлан гарна.
  4. Revit-ээ нээнэ.  Эхний нээлтэд "Add-In Security" асуулт гарвал "Always Load" дарна.

Admin эрх ХЭРЭГГҮЙ.  Revit нээлттэй байсан ч суулгана — Revit-ээ хаагаад дахин нээхэд шинэ хувилбар
ачаалагдана.  Таны тохиргоо, нэвтрэлт, серверт илгээгдээгүй ажлын цаг хөндөгдөхгүй.

Шинэ компьютер: энэ ЗИП дотор БҮХ ЗҮЙЛ бий (Revit 2024–2027 бүрийн файл) — интернэт, өөр юм татах шаардлагагүй.
Хуучин нэмэлттэй компьютер: Install.bat ХУУЧИНД НЬ ДАРЖ шинэчилнэ (Setup exe, хуучин zip, хөгжүүлэгчийн build аль нь ч) —
давхар нэмэлт үүсэхгүй.  Шинэчлэх бүрдээ ХАМГИЙН СҮҮЛИЙН zip-ээр Install.bat-аа дахин ажиллуулахад л болно.
Revit-ийн хувилбар тус бүрээр тусдаа шинэчлэгдэнэ (2024-ийг шинэчлэхэд 2027 хөндөгдөхгүй).

Windows "Windows protected your PC" гэвэл: "More info" → "Run anyway".

УСТГАХ: "Uninstall.bat" (эсвэл Settings → Apps → "MGL Revit <он> нэмэлт").
