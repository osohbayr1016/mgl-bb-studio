# Ханын дэлгээс (Wall Elevations) — `MglWallElevations`

Ribbon: **MGL → Зураг → Ханын дэлгээс**.  Revit 2024–2027 (бүх build).  Runtime AI / интернэт БАЙХГҮЙ — цэвэр C# + Revit API.

## Урсгал

1. Өрөө эсвэл хана сонгоно (урьдчилж сонгоогүй бол товч дарсны дараа сонгуулна).  **1.38.0-аас (2026-10-13, WE-BUG-005):** план эсвэл
   план viewport-той хуудсан дээр ЦОНХГҮЙГЭЭР шууд өрөөн ДОТОР **НЭГ дарна** → өрөө танигдаж урьдчилсан дүн шууд гарна
   (`WeRoomPicker.PickOne`) — хоосон хэсэг, Room Reference X, tag аль нь ч, host ба LINK-ийн өрөө, ШОШГОТОЙ ч ШОШГОГҮЙ ч.  Олдоогүй бол
   шалтгаантай цонх («битүү биш», «энэ давхарт өрөө алга», «link ачаалагдаагүй», «хамгийн ойр өрөө …») + лог-д бүрэн оношлогоо.
   **Esc = «Бусад сонголт»**: «Энэ планы бүх өрөө» (шошгогүй link-ийн өрөө ч), «Олон өрөө сонгох» (`PickMany` — дарах бүрт нэмнэ, дахин
   дарвал хасна, сонгосон өрөө ТҮР бүдүүн хүрээ + «✓ нэр»-ээр тодорно, Esc = дуусгах), «Элемент сонгох» (хуучин `PickObjects` + «Finish»).
   Хуудсан дээр viewport-ыг идэвхжүүлэх шаардлагагүй.  Дэлгэрэнгүй, нотолгоо: доорх «Release gate».
2. Цонх: зүүн талд тохиргоо, баруун талд **урьдчилсан дүн** — загварт ХҮРЭХГҮЙ (цэвэр төлөвлөгч).
3. «Үүсгэх» → цонх хаагдаж команд ДУУСНА; ажил **арын горимд** (Revit-ийн Idling, «Зураг клонлох»-той ижил хост) жижиг алхмаар явна —
   хүлээх хооронд Revit-д үргэлжлүүлэн ажиллана.  Явц, тайлан, «Хуудас нээх», «Бүгдийг буцаах» баруун талын **«MGL — Ажлын явц»** самбарт
   (доорх «Арын горим ба хурд»).  Хост бэлэн биш үед (OnStartup-д бүртгэл унасан) хуучин синхрон зам: нэг `TransactionGroup`, нэг Ctrl+Z.

«Харагдац + хуудас» горимд өрөө тус бүр **баримт бичгийн хуудас** (2026-10-06, 2-р шат — доорх «Баримт бичгийн хуудас»):
түлхүүр байгуулалт (план), бүх талын дэлгээс, 3D харагдах байдал, перспективын байр, legend — жишээ зургийн (205A-F) бүтэц.

## Харагдацын стратеги — Elevation маркер (өгөгдмөл) эсвэл Section

**2026-10-07-ноос өгөгдмөл = Revit-ийн жинхэнэ Elevation** (`View → Elevation`, `ElevationMarker`) — архитекторын гараар хийдэгтэй
ижил: Project Browser → Elevations («Ханын дэлгээс» бүлэг), түлхүүр планд жинхэнэ маркер, сум дээр detail number («205A»).  Цонхны
«Дэлгээсийн хэлбэр» → «Section — зүсэлт» нь хуучин зан төлөв (`ViewSection.CreateSection`).  Хоёулаа `IWallElevationViewFactory`-ийн
ард (`ElevationViewFactory`, `SectionElevationViewFactory`); crop/гүнийг хоёулаа ижил `ApplyCrop`-оор тавина.

Маркерын төлөвлөгч `Core/WeMarkers.cs` (`WeMarkerPlanner`, Revit-гүй, тесттэй): өрөөний талуудыг аль болох ЦӨӨН маркерт хуваалцуулна —
тэгш өнцөгт өрөө = төвд НЭГ маркер 4 сумтай; L/олон талт өрөөнд сум бүр өөрийн ханын өргөний дотор, ханаас ≥300 мм өмнө, өрөөн дотор
байх нөхцөлөөр шунахай бүлэглэнэ (пилястрын нарийн нүүр өөрийн маркертай); хана горимд дэлгээс бүр өөрийн маркер.  Налуу өрөөнд маркер
эргэнэ.  Хуучин (Section) дэлгээс байгаа бол хэвээр шинэчлэгдэнэ — төрлийг солихгүй.

Өөрийн харагдацын төрөл «Ханын дэлгээс» («Building Elevation»-аас; нэр давхцвал «Ханын дэлгээс (Elevation)»): загвар (view template)
наалдахгүй, tag нь **«Detail Number» биетэй** (доорх хэмжилт) — сум дээр «205A», төвд хуудасны дугаар.

## Геометрийн дүрэм

* Чиглэл = ханын шугам / өрөөний хилийн сегментээс; `Wall.Orientation`-оос ЗӨВХӨН тэмдэг (аль тал нь гадна).  Hint
  шугамд перпендикуляр биш бол таахгүй — Failed.
* Өрөө: дотор талыг контурын тэмдэгт талбайгаар (гадна хил / арал) — Revit-ийн контурын чиглэлд найдахгүй; нэмж
  `Room.IsPointInRoom`-оор баталгаажуулна, зөрвөл RequiresReview.
* Хүрээ: гадаргуугийн урт + хүрээний зай; өндөр = өрөөний (өрөө горим) / ханын bbox (хана горим).  Гүн: гадаргуугаас
  `nearOffset` урагш (зүсэх хавтгай), ханын ар талаас `farDepth` цааш.  Location line нь тэнхлэг биш бол зузаанаар нөөцтэй.
* Өрөөний үсэг: харах чиглэлийн компасаар (A = хойд хана …) — хил дахин хуваагдсан ч тогтвортой.

## Дахин ажиллуулах (idempotent)

Түлхүүр = `v1|room:<Room.UniqueId>|wall:<Wall.UniqueId>|side:<ext|int>` (тал = ханын гадна/дотор — хана эргэсэн ч
тогтвортой).  Харагдац дээр түлхүүр + геометрийн тэмдэг + өгсөн нэр + генераторын хувилбар хадгална.
Өөрчлөгдөөгүй → хүрэхгүй; өөрчлөгдсөн → байранд нь шинэчилнэ (эргүүлэх/зөөх/crop, SubTransaction дотор шалгаж буруу бол
буцаана); харагдацгүй → үүсгэнэ; эх нь устсан → «өнчин» гэж мэдээлнэ, УСТГАХГҮЙ.  Хэрэглэгчийн сольсон нэрийг хөндөхгүй.

## Transaction

(Синхрон зам; арын горимд алхам бүр өөрийн `TransactionGroup` — «Арын горим ба хурд».)  `TransactionGroup` → (1) харагдац (дэлгээс тус бүр SubTransaction) → (2) төрөл/масштаб/загвар/far clip → (3) шалгалт
(уншина; буруу ШИНЭ харагдацыг устгана) → (4) хуудас (тусдаа transaction; унавал зөвхөн хуудас буцна) → `Assimilate`.
Collector нь нэг удаа; `Regenerate` зөвхөн эргүүлэх/зөөх ховор зам ба хуудасны title block-ийн хэмжээнд нэг удаа.

### Бүтэн урсгал — жинхэнэ цонхтой (133/133)

Ribbon команд ба шалгалт ЯГ НЭГ `WallElevationWorkflow`-ийг ажиллуулна (`IWeWorkflowUi`: Revit-д TaskDialog/WPF, шалгалтад

төрөлтэй, «Нээх» = эхний дэлгээс · E2 дахин ажиллуулахад «1 дэлгээс үүсгэх» + «15 өөрчлөлтгүй», хасахад товч идэвхгүй,
болиход загвар хөндөгдөөгүй · E3 1:25 + хуудас → 15 шинэчилсэн + 1 шинэ, 4 хуудас/16 viewport давхцалгүй · E4 хана

## Тэмдэглэгээ — хэмжээс, spot level, шошго, keynote (2026-10-06)

Цонхны **«Тэмдэглэгээ»** хүснэгт: мөр = элемент (Хана · Хаалга · Цонх · Тааз · Шал, хучилт · Давхар · Тэнхлэг (ойс) ·
Сантехник · Ерөнхий модел · Тусгай тоног төхөөрөмж · Тавилга · Тогтмол тавилга · Хөшиг ханын хавтан), багана = Spot level ·
Хэмжээс · Шошго · Keynote.  Хамааралгүй нүдэнд «–».  Хэрэглэгч ЯМАР элемент дээр ЮУ тавихыг харагдац үүсгэхдээ сонгоно; товчны
доор «Тэмдэглэгээ: N хэмжээс, M spot level …».  Хэмжээс/spot/keynote-ийн төрөл, зай (мм, цаасан дээр) — сонголттой.

Эзний дүрэм (2026-10-06):

* **Босоо 1-р эгнээ** (баруун талд): шалны доод · шалны дээд · таазны доод · дээд хучилтын доод — нэг гинж (шалны зузаан |
  тааз хүртэл | хучилт хүртэл).  **2-р эгнээ** (гадна талд): давхар хоорондын (түвшин → түвшин).  Түвшний тэмдгийг
  (ЗӨВХӨН энэ харагдацад) хэмжээсний гадна сунгана.
* **Spot level**: хаалганд ЗӨВХӨН дээд ирмэг; цонхонд доод + дээд; таазны доод ирмэг (leader-ээр, хүрээний зүүн гадна).
* **Хэвтээ гинж** (доор): сонгосон элементийн ирмэгүүд — харах ханын хоёр зах, хаалга/цонхны хоёр ирмэг, дэлгээсийг огтлох
  тэнхлэг, өрөөнд байгаа дундах хана, сантехник/ерөнхий модел/тоног төхөөрөмж/тавилга (жишээ: ариун цэврийн өрөө) + нийт урт.

* Зөвхөн ЭНЭ өрөөний өмнөх бүс (хөрш өрөөний тааз, ханын цаадах юм орохгүй).  Дахин ажиллуулахад ӨӨРИЙН өмнө тавьсныг устгаж
  дахин тавина (хэрэглэгчийн гараар тавьсныг хөндөхгүй); зөвхөн тэмдэглэгээ өөрчлөгдсөн бол харагдац хөдлөхгүй
  («Тэмдэглэгээ шинэчлэгдэнэ»).  Хүснэгтийг бүгдийг унтраавал өмнө тавьсныг арилгана.

## Арын горим ба хурд (2026-10-07)

Эзний хүсэлт: «хуудас үүсгэх дарсны дараа mouse loading болоод Revit-ээ ашиглаж чадахгүй — зураг клонлох шиг хүлээх хооронд дараагийн
зургаа хийж суумаар байна; илүү хурдан».  GATEWAY дээр (өрөө 310, 8 тал) нэг ажил Revit-ийг **45 с** түгжиж байсан.

**Бүтэц.**  `ElevationGenerationCoordinator` = алхмын машин (`Begin` → `Step` … → `Done`); синхрон `Run` = ижил алхмууд нэг
`TransactionGroup`-д.  `WeJob` (`IMglJob`) алхам бүрийг НЭГ `TransactionGroup`-д («MGL дэлгээс #3 · 310A (1/8) — харагдац…» — Undo-д нэг
мөр) хостын Idling-д гүйцэтгэнэ.  `CdJobHost` (2026-10-01 «Зураг клонлох») ерөнхий болсон (`CloneDrawings/MglJob.cs`), самбар
«MGL — Ажлын явц».  Ажил эхлэхдээ нөөц/сонголт/төлөвлөгөөг ДАХИН уншина (дараалалд хүлээх хооронд загвар өөрчлөгдсөн байж болно;
нэг өрөөнд хоёр ажил давхар дэлгээс үүсгэхгүй).  Ctrl+Z манай алхмыг буцаавал түр зогсооно.  «Бүгдийг буцаах» = энэ ажлын ҮҮСГЭСЭН
харагдац, хуудас, хоосорсон маркер (шинэчилсэн өмнөх харагдацыг хөндөхгүй — анхааруулна).  Дууссаны дараа хэрэглэгч эхэлсэн
харагдацаасаа шилжээгүй бол эхний хуудсыг нээнэ; шилжсэн бол хөндөхгүй (самбарт «Эхний хуудсыг нээх»).

## Баримт бичгийн хуудас — 2-р шат (2026-10-06)

Даалгавар: өрөө сонгоход жишээ хуудас (205A-F, 205G-N, 206A-G) шиг **бүрэн баримт бичгийн хуудас** — түлхүүр байгуулалт, бүх талын
дэлгээс, ангиллаар тусдаа хэмжээс, танигдсан элемент, 3D, перспективын байр, тэмдэглэл/материалын бүс.  Бүх шийдвэр ЦЭВЭР цөмд
(тесттэй), Revit давхарга зөвхөн хэрэгжүүлнэ.

### Тал (нэг дэлгээс) — `RoomBoundaryAnalyzer.Sides`

* **Нэг шулуун = нэг дэлгээс** (`MergeCollinear`, өгөгдмөл асаалттай): контурын нэг шулуун дээрх (дотор нормаль ижил, ≤ 5 мм) бүх шулуун
  сегмент — хэд хэдэн хана, дундах багана / тусгаарлах шугам — нэг тал (жишээ зургийн 205C: шил хана + улаан хавтан + модон багана).
  Шулууны хоёр хэсгийн ЗАВСРЫГ давах нь завсарт орсон бүх хил шугамаас ≤ 1 м (`WallElevationPlanner.MaxJogMm`) — пилястр, ниш давагдана,
  гүн U хонхор, урт хаалт хана давагдахгүй (тусдаа тал).  Цухуйлт → зүсэх хавтгай түүнээс өмнө; ниш → гүн түүнийг хамарна.
* **Түлхүүр тогтвортой**: зангуу = хамгийн урт хана → `v1|room|wall:<зангуу>|side` (нэг ханатай тал нэгтгэхгүй горимтой ЯГ ижил — тэгш өнцөгт
  өрөөнд горим солиход шинэ харагдац үүсэхгүй).  Нэг хана хоёр тал болбол 2 дахь нь `|part:2`.  Нэгтгэгдсэн бусад ханын хуучин
  дэлгээсийг «нэг шулуун дээрх хөрш хананы дэлгээстэй нэгдсэн» өнчин гэж мэдээлнэ (устгахгүй).  ⚠️ Нэгтгэхэд үсэг (A, B …) шилжиж болно —
  нэрэнд {Side} байвал «Нэр шинэчлэгдэнэ».
* Хана огт ороогүй тал (зөвхөн тусгаарлах шугам / link) — дэлгээсгүй, мэдэгдэнэ.  Тал завсраа давахдаа хамарсан хил (ханын тэнхлэг
  дээр тавьсан тусгаарлах шугам — Revit-ийн хилд нүүрээс ~100 мм ард, холбоос сегменттэй) тэр дэлгээст багтсан тул «дэлгээсгүй» гэж
  мэдээлэхгүй.  Муруй хана — Unsupported (хуучин шиг).
* **Харах гүн** (`DepthMode`, өгөгдмөл «Өрөөний дунд хүртэл»): талын 5 цэгээс дотор нормалийн дагуу цацраг → эсрэг хил (медиан) / 2,
  дээд хязгаар `MaxDepthMm` (8 м).  Revit-ийн дотоод дэлгээсийн тэмдэгтэй ижил — өрөөнд байгаа тавилга харагдана.  «Тогтмол» = хуучин
  `NearOffsetMm`.  ⚠️ Хажуу ханын цонх/хаалга зүсэлтэд (огтлолоор) харагдана — дотоод дэлгээсийн хэвийн дүр.

### Хуудасны зохиомж — `WeSheetComposer`
