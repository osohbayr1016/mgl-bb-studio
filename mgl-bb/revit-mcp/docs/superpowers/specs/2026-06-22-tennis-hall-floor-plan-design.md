# Теннисний ордон — шинэ floor plan дизайн (spec)

- **Огноо:** 2026-06-22
- **Төлөв:** Батлагдсан (хэрэгжүүлэхэд бэлэн)
- **Лавлагаа:** "Монголиан Рейсинг Трак" ХХК-ийн "Талбайн теннисний ордон", 1-р давхрын план, MGL E&C, M 1:250 (96м × 50м, нэг теннисний талбай, нийт 77 өрөө, 4543.95 м²)

## 1. Зорилго

Лавлагаа зурагтай төстэй боловч дараах 3 өөрчлөлттэй теннисний ордны 1-р давхрын floor plan-ыг Revit-д шинээр загварчлах:

1. **Хоёр теннисний талбай** (нэгийн оронд).
2. **Үзэгчдийн суудал нийт 150** хүртэл.
3. Барилгын хэлбэрийг **дөрвөлжин** болгох.

## 2. Хамрах хүрээ

**Багтах:**
- Шинэ metric Revit project дотор зөвхөн **1-р давхар (L1)**.
- Грид, гадна хана, дотоод хана, 77 өрөө (Room + нэр + дугаар), 2 талбайн зураас, 2 арц (нийт 150 суудал), гол хаалганууд, өрөөний шошго.

**Багтахгүй (out of scope):**
- Дээд давхрууд, дээвэр, фасад, MEP, бүтцийн тооцоо.
- Лавлагааны өрөөний талбайг яг тэнцүүлэх (дахин төлөвлөсөн план — нэр/дугаар/функц хадгална).

## 3. Ерөнхий тохиргоо

| Зүйл | Утга |
|------|------|
| Формат | Revit шинэ загвар (run_revit_code / Roslyn C#) |
| Нэгж | Метр / мм (UnitUtils.ConvertToInternalUnits ... Millimeters) |
| Давхар | Зөвхөн L1 |
| Document | Шинэ/хоосон metric project (Snowdon Towers БИШ) |

## 4. Грид ба гадна хана

- **Footprint:** ~65м × 65м дөрвөлжин (≈4225 м²).
- **Грид:** X1–X9, Y1–Y9, **8м алхамтай** (8 × 8 = 64м). Эхлэл цэг (0,0) баруун доод булан.
- Гадна хана периметрээр; өмнө талд (Y1 ирмэг) орцны нээлхий.

### Хойд бүс (кафе / гал тогоо)

## 6. Хоёр теннисний талбай

- ITF стандарт: тоглоомын зураас **23.77м × 10.97м**, run-off-той нийт **~36м × 18м/талбай**.
- **2 талбай зэрэгцээ**, урт тэнхлэг хойд–урд (Y чиглэл). Нийт төв заал ~36м × 37м.
- Зураасыг model line эсвэл filled region-оор тэмдэглэнэ (тор, base line, service line, singles/doubles).

## 7. Үзэгчдийн суудал — 2 × 75 = 150

- **Хоёр арц**, заалын эсрэг хоёр урт талд.
- Тус бүр ~75 суудал: **5 эгнээ × 15 суудал** (≈7.5м өргөн × 4м гүн шаталсан платформ) — нийлбэр 150.
- Шаталсан платформыг floor/extrusion-оор, суудлыг generic model марк/эгнээгээр схематик дүрсэлж, "Арц-1/2 (75 суудал)" гэж шошголно.

## 8. Modeling дараалал

1. Шинэ metric Revit document үүсгэх / идэвхжүүлэх.
2. Level L1 баталгаажуулах.
3. Грид (X1–X9, Y1–Y9, 8м).
4. Гадна периметр хана (65×65 дөрвөлжин).
5. Бүс хуваах гол дотоод хана (төв заал + 4 цагираг бүс).
6. Бүсүүдийн дотоод хуваах хана (өрөөнүүд).
7. Room placement + нэр/дугаар (77 өрөө).
8. 2 талбайн зураас (model line / filled region).
9. 2 арц (платформ + суудал) — нийт 150.
10. Гол хаалганууд (орц, бүс хооронд).
11. Өрөөний шошго (room tag) — L1 plan view дээр.

Бүх алхам `run_revit_code` (Roslyn C#)-оор; нэгж мм-ээр оруулж feet рүү хөрвүүлнэ.

## 9. Document setup (эрсдэл)

`run_revit_code` нь идэвхтэй Doc дээр нэгэнт нээгдсэн "MCP Script" transaction дотор ажилладаг. Тиймээс:

- **Сонголт А (эхэнд оролдох):** API-аар шинэ metric project үүсгэх (`Application.NewProjectDocument` + `OpenAndActivateDocument`). Энэ нь нээлттэй transaction-той зөрчилдөж болзошгүй.
- **Сонголт Б (fallback):** Хэрэглэгчээс хоосон metric project нээж идэвхжүүлэхийг хүсэх, дараа нь түүн рүү загварчлах.

Энэ асуудлыг хэрэгжүүлэлтийн төлөвлөгөөний эхний алхамд шийднэ.

## 10. Fidelity / хязгаарлалт

- Дахин төлөвлөсөн план — өрөөний талбай лавлагаатай яг тэнцэхгүй.
- Хана схематик зузаантай (interior partition / generic).
- Талбайн зураас, суудал схематик (тоглоомын болон бүтцийн нарийвчлал бус).

## 11. Амжилтын шалгуур

- Revit-д ~65×65м дөрвөлжин барилга, 8м грид.
- Төв заалд 2 тоглоомын талбайн зураас зэрэгцээ.
- Нийт 150 суудалтай 2 арц (эсрэг 2 талд).
- 77 өрөө нэр/дугаартай, цагираг бүсэд логиктой байрласан.
- L1 plan view дээр шошготой, ойлгомжтой харагдах.

## 12. Нээлттэй асуудал

- Document үүсгэх арга (§9) — хэрэгжүүлэлтэд баталгаажна.
- Хоосон project-д тохирох wall type / chair family байхгүй бол generic/built-in хувилбар ашиглана.
