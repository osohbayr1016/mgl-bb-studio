## Архитектурын шийдвэрүүд

- **Revit-ийг НЭГ удаа уншина, дараа нь ЦЭВЭР хөдөлгүүр.**  `Capture` → immutable DTO → `NumberingEngine` олон удаа (товч бүрт Revit API дуудахгүй)
  → `Apply` нэг удаа.  ViewModel нь амьд `ViewSheet`/`Parameter` барихгүй; Revit-ийн ажил БҮГД `SheetNumeratorBridge` (ExternalEvent)-ээр.
- **Нэг instance.**  Цонх нээлттэй үед команд дахин дуудвал шинэ цонх нээхгүй, байгааг идэвхжүүлнэ (minimized бол сэргээнэ); `IsLoaded` биш `_window != null`-оор
  шалгадаг тул `Loaded`-ийг хүлээхгүйгээр хурдан давхар дуудлага ч нэг цонх үлдээнэ (Revit дотор 3 дуудлага ЯГ НЭГ script-д шалгасан).
  Цонх хаагдахад bridge (`ExternalEvent`) Dispose хийгдэнэ.
- **Typed `GroupKey`** (`BrowserFolder | SheetCollection | Assembly | AllSheets` + зам + id): харагдах нэр хэзээ ч түлхүүр биш —
  нэр давхцсан ч өөр эх/төрөл/id-тай бол ТУСДАА бүлэг.
- **Preview ҮРГЭЛЖ анхны snapshot + одоогийн тохиргооноос** тооцогдоно (түр утга Revit-д бичихгүй, угтвар/дагавар/нэр давхарлагдахгүй).
- **Нэг давхардлын шалгалт**, нэг Монгол мессежийн файл (`Msg`), нэг Sheet Collection орох цэг, нэг Apply.
- **Setter нь эцсийн шийдэгч.**  Манай хориглосон тэмдэгтийн жагсаалт зөвхөн УРЬД шалгалт; Revit setter татгалзвал TransactionGroup бүхэлдээ буцна.
- **Хөдөлгөөнгүй `catch {}` БАЙХГҮЙ** (өөрчлөлт хийх кодод): алдаа → лог (`%APPDATA%\RevitMcpAddin\sheet-numerator.log`) + товч Монгол мессеж.

## Дугаарлалтын алгоритм

**Горим** (`RenumberSettings.EffectiveMode`, давуу эрэмбээр): `CleanMarkers` > `Move` > `Shift` (Өсгөх/Бууруулах идэвхтэй) > `Advanced` (tab) > `Simple`.

**Конвейер** (`NumberingEngine.Compute`):
тохиргооны шалгалт (буруу бол юу ч үүсгэхгүй) → горимын үндсэн дугаар → параметрийн угтвар/дагавар → захын хоосон зайг Revit-ийн адил тайрах,
хоосон/хориглосон тэмдэгт шалгах → (сонголтоор) үл үзэгдэх тэмдгээр давхардал ялгах → нэр → параметр бичих → **давхардал (БҮХ хуудастай)**.

- **Энгийн:** `Угтвар + (Эхлэх + k, өргөнтэй) + Дагавар`.  Өргөн = ДООД талын цифрийн тоо: `4,w3 → 004`, `-4,w3 → -004`, `1234,w3 → 1234`
  (хасах тэмдэг цифр биш, ХЭЗЭЭ Ч тайрахгүй).  «Эхлэх дугаар ашиглах» унтраалттай бол `Угтвар + ОДООГИЙН дугаар + Дагавар`.
  Тоо ±999 999 999 999 999-д хязгаарлагдана; халвал мөр АЛДААТАЙ (чимээгүй халихгүй).
- **Нарийвчилсан (odometer, `PartSequence`):** 3 хэсэг, хэсэг бүр `Угтвар + тоо + Дагавар`; тоо = `Тоогүй | Тогтмол | Өсөх | Буурах`
  (эхлэх, алхам ≥ 1, өргөн, хязгаар).  Дүрэм: ХАМГИЙН БАРУУН өөрчлөгдөх хэсэг мөр бүрт нэг алхам; хязгаарт хүрвэл эхлэх утга руу буцаж
  ЗҮҮН хөрш нэг алхам (`A-1-1…A-1-5, A-2-1…`) — «Хязгаарт хүрвэл эхлэх утга руу буцаж, өмнөх хэсгийг нэмэх» асаалттай үед; үгүй бол
  хязгаар давсан мөр, түүнээс хойшхи бүх мөр `PartLimitExceeded` АЛДААТАЙ.  Хоосон хэсэг, тусгаарлагч давхар гарахгүй
  (хэсэг 2 хоосон бол 1→3 нь `Тусгаарлагч 1`-ийг ашиглана).  Тусгаарлагч нь ДУРЫН бичвэр (түгээмэл сонголттой).
- **Одоогийн дугаарын тоон хэсгийг өөрчлөх (`ExistingNumberShift`):** тоон хэсэг = ASCII цифрийн залгаа; «-» нь ЦИФРИЙН ЯГ ӨМНӨ, ба
  (мөрийн эхэнд эсвэл өмнөх тэмдэгт үсэг/цифр БИШ) үед л сөрөг тэмдэг: `A-01` → [01], `01-02` → [01][02], `-001` → [-001], `A--004` → [-004].
  Нэг хэсэгтэй бол тэр; олонтой бол ӨГӨГДӨЛ сүүлийнх + анхааруулга (аль хэсгийг ашигласан) + «Тоон хэсэг» сонгогч.  Тоо байхгүй бол
  «Тоон хэсэг олдсонгүй.»  Тэргүүлэх тэгтэй бол өргөн хадгална (`001 + 2 → 003`), цифр нэмэгдвэл тайрахгүй (`999 + 1 → 1000`), тэгийг давж болно.
- **Зөөхөд дугаар дагуулах (`Move`):** бүлгийн АНХНЫ дугааруудын дараалал (OriginalOrder-ийн байрлал бүрийн дугаарын СТРИНГ) хэвээр,
  зөвхөн хуудсууд WorkingOrder-оор тэдгээрийг авна — тоон задлал ШААРДАХГҮЙ (`A-001`, `ЕХ-А` аль ч).
  Зөөхөд энэ горим унтраалттай бол WorkingOrder «бохир» болж, улбар шар «Жагсаалтын дараалал Project Browser-оос өөрчлөгдсөн байна.»;
  Move-г дахин асаах нь «Хэрэгжүүлэх» эсвэл «Жагсаалтыг шинэчлэх» хүртэл хаалттай.
- **Нэрэнд дугаар:** нэрийн эхэнд/төгсгөлд `үүсгэсэн хэсэг` (бүтэн дугаар эсвэл Хэсэг N-ийн бүтэн/тоон), тусгаарлагчтай.  Эх бичвэр нь
  ҮРГЭЛЖ snapshot-ын АНХНЫ нэр.  ⚠️ **Гүйцэтгэх бүрт дахин НЭМНЭ** (ModPlus-тай ижил) — урьдчилсан харалт яг юу болохыг харуулна
  (хоёр дахь Apply-ийн дараа «Нэр · 010 · 010» харагдана).
- **Параметр бичих:** `Үр дүнг параметрт бичих` (бүтэн дугаар/хэсэг), `Бүлгийн хуудасны тоо` (зөвхөн эхний ӨӨРЧЛӨГДӨЖ БУЙ хуудсанд/бүх хуудсанд;
  тоо нь бүлгийн БҮТЭН хуудасны тоо).  Зорилт: ЗӨВХӨН бичих боломжтой Текст, Бүхэл тоо, Нэгжгүй тоо.  Урт/талбай/өнцөг, Yes/No, ElementId,
  read-only, параметр байхгүй → ХААЛТТАЙ (тайлбартай).  ⚠️ **Утга аль хэдийн ижил бол өөрчлөлт БИШ** (`ParameterRules.IsUnchanged`; Текст ба Бүхэл тоо) —
  хэрэгжүүлсний дараа харалт «өөрчлөлтгүй» болж «Хэрэгжүүлэх» хаагдана, давтан Apply Undo-ийн илүү алхам нэмэхгүй.  Нэгжгүй тоог (Number) таниагүй:
  snapshot-ын текст нь Revit-ийн дугуйруулсан харуулах хэлбэр тул «ижил» гэж таамаглахгүй, үргэлж бичнэ.
- **Сонгосон хуудаснаас эхлэх:** WorkingOrder-ийн сонгосон индексээс доош л өөрчлөгдөнө; өмнөх хуудас хэвээр боловч давхардлын шалгалтад ОРНО
  (`01 02 [02] 03` → шинэ «02» нь өөрчлөгдөөгүй «02»-той мөргөлдөж татгалзагдана).

### Давхардлын нэгдсэн шалгалт (`DuplicateValidationService`)

Өөрчлөгдөж буй мөр бүрийг document-ийн БҮХ хуудастай (өөр бүлэг, нуугдсан, placeholder, assembly, эхлэлээс өмнөх) тулгана.
Хүрээ (`ScopeKey`): assembly → `A<assemblyId>`; Revit 2025+ → `C<collectionId>` (цуглуулга бүрт тусдаа); Revit 2024 → `G` (глобал).
Харьцуулалт том/жижиг үсэг ҮЛ ЯЛГАНА (Revit хэмжсэн), Unicode НОРМЧЛОЛГҮЙ.  Түлхүүр = `хүрээ + дугаар` (Dictionary, O(n)).
Мессеж: «Дугаар давхардсан байна.\n“{number}” дугаар энэ дугаарлалтын хүрээнд аль хэдийн ашиглагдаж байна.» + давхцсан хуудсууд.
Apply-ийн ӨМНӨ ДАХИН (Revit-ийн ҮНЭН одоогийн дугаарууд дээр) шалгана — snapshot хуучирсан байж болох тул.

## Apply — хоёр шатлалт түр дугаар (АТОМ)

Шууд нэг нэгээр нь оноож БОЛОХГҮЙ: `A: 01→02`, `B: 02→01` солилтод Revit дугаар бүрийг оноох бүрт давхардал шалгадаг (`ArgumentException`).

```
1. Хуучирсан эсэх шалгах (document, хуудас, дугаар/нэр, параметрийн холбоо)        ── юу ч бичихгүй, хуучирсан бол зогсоно
2. Давхардал, хориглосон тэмдэгт (ҮНЭН дугаарууд дээр); worksharing: GetCheckoutStatus/GetModelUpdatesStatus  ── checkout ХИЙХГҮЙ
3. TransactionGroup «MGL – Зургийн хуудас дугаарлах»
   Transaction A «MGL – Түр дугаар»:        өөрчлөгдөх хуудас бүрт  MGLTMP_<8-hex>_<i>   (оршиж буй дугаартай мөргөлдөхгүй token)
   Transaction B «MGL – Хуудасны дугаар, нэр»: эцсийн дугаар → нэр → параметр; бүгдийг буцаан уншиж тулгана
4. Баталгаажуулалт: бүх дугаар төлөвлөснөөр бичигдсэн эсэх
5. tg.Assimilate()  → НЭГ Undo
Алдаа (setter ArgumentException, commit амжилтгүй, баталгаажуулалт таарахгүй) → tg.RollBack() → дугаар/нэр АНХНЫХ болсныг ҮНЭН уншиж баталгаажуулна
```

Үр дүн (`ApplyOutcome`): `Applied`, `NothingToDo`, `Stale`, `Blocked` (давхардал/эзэмшил/параметр — юу ч бичигдээгүй),
`RolledBack` (буцаалт БАТАЛГААЖСАН — «ямар ч өөрчлөлт хадгалагдсангүй» гэж ЗӨВХӨН энэ үед хэлнэ), `RollbackUnverified`
(буцаалтыг баталгаажуулж чадсангүй — «Ctrl+Z ашиглана уу» гэж ил хэлнэ).  Тестийн цоорхой `RenumberApplyService.FailAtStage = "after-temp"`
(түр дугаар commit хийсний дараа зориуд алдаа) — үйлдвэрлэлд ХЭЗЭЭ Ч тохируулагдахгүй.
Failure preprocessor: warning-ийг устгана, алдаа бол Transaction-ийг буцаана (`ProceedWithCommit` ХЭЗЭЭ Ч).

## Хэвлэгддэггүй Unicode тэмдэг

Сонголттой (унтраалттай эхэлнэ), `ТӨЛӨВ`-ийг ИЛ харуулна.
- **Каталог** (`UnicodeMarkerCatalog`): U+200B, 2060, 200C, 200D, FEFF, 2063, 2062, 2061, 034F, 00AD, 200E, 200F + U+180E (Монгол эгшиг тусгаарлагч).
  Каталог = НЭР ДЭВШИГЧ, баталгаа БИШ.
- **Probe** (`UnicodeProbe`): тэмдэг бүрийг placeholder хуудасны дугаарын төгсгөлд тавьж setter-ээр бичээд буцааж уншина; ХОЁР нөхцөлөөр л хүлээн авна —
  (1) буцаан уншсан утга ЯГ ижил (Revit тайраагүй), (2) «base» ба «base+тэмдэг» ЗЭРЭГ оршино.  Бүгд буцаагддаг Transaction дотор (document-д ул мөр үлдэхгүй).
  Revit 2027.2: 12 хүлээн авсан, U+180E тайрагдсан/татгалзагдсан.  Probe хийгээгүй/татгалзсан тэмдэг хаалттай.
- **Эхний хэрэглээний анхааруулга** (`unicode_warning_accepted` санагдана): «Энэ арга нь харагдахдаа ижил боловч дотроо өөр Unicode тэмдэгтэй дугаар үүсгэнэ…»
- **Давхардал ялгах:** өөрчлөгдөж буй мөрийг WorkingOrder-оор нь явж, ХҮРЭЭНД эзлэгдсэн дугаартай давхцвал `base + тэмдэг × k` (k ≤ 64,
  `MakeUnique`).  Өөрчлөгдөөгүй хуудасны дугаарыг ХЭЗЭЭ Ч өөрчлөхгүй (тэд «эзлэгдсэн» олонлог).  ⚠️ Тэмдэг ЗӨВХӨН SheetNumber-д; нэр/параметр бичих эх бичвэр
  (`BaseNumber`) ЦЭВЭР — тэмдэг гоожихгүй.
- **Оношилгоо:** жагсаалт/tooltip-д `A-01⟦U+200B × 2⟧`; мөрийн «Дугаарт хэвлэгддэггүй Unicode тэмдэг байна» анхааруулга.  Одоо байгаа тэмдгийг чимээгүй хаяхгүй.
- **Цэвэрлэх:** «Хэвлэгддэггүй тэмдэг цэвэрлэх» — мэдэгдэж буй тэмдгийг ил, урьдчилж харуулаад устгана (нэр/параметр бичих сонголт хамаарахгүй).
- Internal түр дугаар (`MGLTMP_…`) үл үзэгдэх тэмдэг ХЭЗЭЭ Ч хэрэглэхгүй.

## Хуучирсан байдал, worksharing

- Цонх modeless тул document өөрчлөгдөж болно.  `Freshness` шалгалт цонх идэвхжих бүрт, мөн Apply-ийн өмнө ажиллана (`DocumentKey` = төслийн UniqueId + гарчиг + зам):
  - **хуудас устсан/нэмэгдсэн, дугаар/нэр гаднаас өөрчлөгдсөн** → баннер «Төсөл tool нээгдсэнээс хойш өөрчлөгдсөн байна. Алдаатай overwrite хийхээс сэргийлж жагсаалтыг шинэчилнэ үү.»
    + Apply хаалттай (Apply-ийн өмнөх шалгалт ч юу ч бичихгүй `Stale` буцаана);
  - **идэвхтэй document солигдсон** → эрэмбэ «бохир» БИШ бол шинэ контекстээр ШУУД ачаална (хадгалах зүйлгүй); «бохир» (хэрэгжүүлээгүй зөөлт байгаа) бол баннер
    «Идэвхтэй төсөл солигдсон байна. Жагсаалтыг шинэчилж дахин ачаална уу.» + Apply хаалттай, «Жагсаалтыг шинэчлэх» нь ЭХЛЭЭД зөөлтийг устгах эсэхийг асууна.
- Worksharing: Apply-ийн өмнө хуудас бүрийн `GetCheckoutStatus`/`GetModelUpdatesStatus`; өөр хэрэглэгч эзэмшсэн эсвэл төвд шинэчлэгдсэн/устсан бол
  юу ч бичихгүй зогсоно («Зарим хуудсыг өөрчлөх боломжгүй байна…», хуудас + эзэмшигч).  **Checkout хийхийг ОРОЛДОХГҮЙ** (өөрчлөхөд Revit өөрөө авна).
  ⚠️ Параметрийн ӨМНӨХ утга гаднаас солигдсон эсэхийг шалгахгүй (дугаар/нэрийг л) — параметр бичихийг хэрэглэгч санаатай сонгосон.

### Нэр өөрчлөх / хуудас устгах

Хоёулаа ExternalEvent + Transaction (`SheetEditService`).  Дугаар/нэр нь хэрэглэгчийн харсан утгатай таарахгүй бол `Stale` (бусдын засварыг чимээгүй дарахгүй);
Revit-ийн хориглосон тэмдэгттэй нэрийг setter татгалзана; идэвхтэй харагдацыг устгахгүй.  Устгахад баталгаа: «{дугаар} — {нэр}\nхуудас болон Revit-ийн устгалтай холбоотой
хамааралтай элементүүдийг устгах гэж байна. Үргэлжлүүлэх үү?»; хэрэгжүүлээгүй зөөсөн дараалал байвал баталгаанд «…хэвээр үлдэнэ (зөвхөн устгасан хуудсыг хасна)» сануулга нэмэгдэнэ.
Амжилттай бол жагсаалтыг дахин уншиж зөөсөн дарааллыг (боломжтой бол) хадгална — чимээгүй хаяхгүй.

  одоо `_window != null`.

## Revit дотор автоматаар турших (`tests/SheetNumerator.LiveHarness`)

Автомат (CI) БИШ: Revit-ийг хүн `MGL_ALLOW_EXEC=1`-тэй асаасан (MCP `run_revit_code` нээлттэй) байх ёстой.  Core + Ui + Revit-ийг ЭХ КОДООС эмхэтгэнэ (суулгагдсан add-in-д
хамаарахгүй).  Revit нэг нэртэй assembly-г хоёр дахин ачаалж чаддаггүй тул build бүрд өөр нэртэй DLL:

```
cd revit-mcp/tests/SheetNumerator.LiveHarness
dotnet build -c Release -p:Stamp=<n> -p:Platform=x64          # → bin\<n>\SnLive<n>.dll
```

`run_revit_code` дотор (`Doc`, `UiApp` global):

```csharp
var asm = System.Reflection.Assembly.LoadFrom(@"...\bin\<n>\SnLive<n>.dll");
// 1) Scratch document дээрх 13 шалгалт (templatePath = Revit-д ОДОО нээлттэй БИШ метр загварын хуулбар; `only` = нэрийн хэсэг эсвэл null)
asm.GetType("SnLive.Runner").GetMethod("Run").Invoke(null, new object[] { UiApp, outDir, templatePath, null });
// 2) Жишээ төсөл (дэвсгэрт нээж, хадгалалгүй хаана): snapshot + бүлэглэлт + (true бол) Apply
asm.GetType("SnLive.SampleProbe").GetMethod("Run").Invoke(null, new object[] { UiApp, @"C:\Program Files\Autodesk\Revit 2027\Samples\<файл>.rvt", outDir, true });
```

Шат дамжлагат цонхны шалгалт (`SnLive.UiStage`; ExternalEvent нь handler дуусмагц л ажилладаг тул АЛХАМ БҮР тусдаа `run_revit_code`):
`Open` → `State`/`Set(key,value)`/`Apply`/`Shot(name)` → `Close`; жишээ төсөл дээр `OpenOnDoc`/`CloseDoc` (синхрон gateway); ribbon командыг
`CommandExecute`/`CommandInfo`/`CommandClose`/`CommandWindowState` (ExternalCommandData-г reflection-оор үүсгэнэ); идэвхтэй document солих `ActivateLater`/`SwitchResult`
(ExternalEvent-ээр — `run_revit_code`-ын нээлттэй Transaction дотроос `OpenAndActivateDocument` дуудаж БОЛОХГҮЙ).

**Browser-ийн эрэмбийг БОДИТООР харьцуулах** (`SnLive.BrowserOracle`): `SeedFromSample` (жишээ төслийн дугаар+нэрийг идэвхтэй scratch document-д үүсгэнэ) →
`WriteOrder` (манай эрэмбийг файлд) → UI Automation-аар Project Browser-ийн «Sheets (all)»-ийг дэлгэж (`OperatorIcon`-д InvokePattern — хулганы хөдөлгөөнгүй) `ListItem`-үүдийг
дарааллаар нь унших → хоёр файлыг харьцуулах.  Chromium нь жагсаалтыг виртуалчилдаг (~40 мөр DOM-д) тул `ScrollItemPattern.ScrollIntoView`-ээр гүйлгэж давхцлаар нь залгана.
Дууссаны дараа Browser-ийн мод, scratch хуудсыг ЭХНИЙ ТӨЛӨВД буцаа.

⚠️ Замын анхааруулга (Revit-ийн гацаалт): Revit-д ОДОО нээлттэй .rte файлаар `NewProjectDocument` хийвэл «Unable to Access the Model» модаль цонх;
ижил assembly-тай хоёр хуудас үүсгэвэл «assembly match» модаль.  Модаль цонх main thread-ийг гацаана — харness-ийг хянагчтай (BM_CLICK-ээр «Cancel») ажиллуул.

## Бүрэн бус / мэдэгдэж буй хязгаарлалт

- **Website-ийн тусламжийн хуудас хийгээгүй** (даалгаварт «боломжтой, add-in дууссаны дараа» гэснээр).
- `Revit 2024/2025/2026` ажиллах орчинд шалгаагүй (эмхэтгэл л); Revit 2024-д Sheet Collection байхгүй (глобал давхардал) — API-аас, хэмжээгүй.

- Нэгжгүй тоон (Number) параметрийн «ижил утга» танилт хийгээгүй (үргэлж бичнэ).
- Параметрийн ӨМНӨХ утга гаднаас солигдсоныг шалгахгүй (зөвхөн дугаар/нэр/оршихуй/бичих боломж).
