MGL тооцооны тайлан — 0.3.0
=============================

0.3.0-д шинэ: LIRA-аас ШИЛЖИЛТИЙН ХУУДАС автоматаар
  LIRA-д тооцоотой загвараа нээж үр дүн харах горимд «MGL тооцооны тайлан» →
  дээд талын «LIRA» → «Шилжилтийн хуудас үүсгэх». Хослол (SE+X, SE+Y, XY),
  бүрэлдэхүүн, харагдацаа (фасад / план) сонгоод «Хуудас үүсгэх» —
  өнгөт зураг + «min=…mm / max=…mm» бүхий 5.2 маягийн хуудас үүснэ.
  Зураг, тоо гараар хуулах шаардлагагүй. Алдаа гарвал «LIRA → Оношилгоо»
  файлыг хөгжүүлэгчид явуулна.

Бүтээцийн тооцооны тайланг компанийн загвараар (хүрээ, булангийн хүснэгт,
нүүр хуудас) Word-оор гаргана. Төмөр бетон, металл бүтээцийн тайлан тусдаа.

Шаардлага
  - Windows 10/11, админ эрх хэрэггүй
  - «ISOCPEUR MON» фонт (Revit/AutoCAD-тай хамт ирдэг). Суугаагүй бол
    суулгагч анхааруулна.
  - LIRA 10.12 — заавал биш. Суусан бол LIRA-ийн цэсэнд ч нэмэгдэнэ.

Суулгах
  1. LIRA нээлттэй бол хаана.
  2. Zip-ийг бүтнээр нь нэг хавтсанд задална («Extract all»).
  3. Install.cmd дээр давхар дарна.

Хэрэглэх
  - Desktop дээрх «MGL Тооцооны тайлан»-г нээнэ, эсвэл LIRA-д тооцоотой
    загварын үр дүн харах горимд цэснээс «MGL тооцооны тайлан».
  - «Шинэ тайлан» → Төмөр бетон / Металл бүтээц.
  - «Төслийн мэдээлэл…» — төслийн нэр, байршил, шифр, захиалагч, инженер,
    лиценз, огноо. Нүүр хуудас, 2-р хуудас, булангийн хүснэгт бүгд эндээс.
  - «+ Хуудас» — шинэ хуудас. Хуудас бүрт «+ Гарчиг», «+ Текст», «+ Зураг»,
    «+ 2 зураг зэрэгцээ». Зургийг файлаас сонгох, чирж оруулах, эсвэл
    LIRA-аас хуулаад «Буулгах (clipboard)». Зураг бүрт тайлбар бичнэ.
  - «Хадгалах» — .mglrep файл (Documents\MGL-LIRA\Тайлан).
  - «Word гаргах…» — бэлэн .docx.

Устгах
  Uninstall.cmd дээр давхар дарна. Таны тайлангийн файлууд үлдэнэ.
