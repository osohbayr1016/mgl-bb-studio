## 4. Атрибуци — ЗААВАЛ БИЕЛҮҮЛЭХ

Apache-2.0 §4 нь дахин түгээхэд дараахыг шаарддаг. **Бүгд биелүүлэгдсэн:**

| Шаардлага | Хаана биелэв |
|---|---|
| §4(a) лицензийн хуулбар дагалдуулах | `ai/registry/licenses/Qwen3-8B-LICENSE.txt` (+ түүхэн `Qwen3-4B-Instruct-2507-LICENSE.txt`) |
| §4(b) өөрчилсөн файлыг тэмдэглэх | Fine-tune хийвэл `ai_model_releases.adapter` + `dataset_version` нь өөрчлөлтийг мөшгинө |
| §4(c) NOTICE дамжуулах | Суурь репод NOTICE файл байхгүй — шаардлага үүсэхгүй |
| §4(d) атрибуци харагдуулах | Доорх хүснэгт |

### Хаана юу харагдах вэ

Мандат §1: «Do not expose third-party base-model branding as the main product
name in the UI» — гэхдээ мөн «Maintain proper attribution/license files
internally». **Зөрчил байхгүй:**

| Газар | Юу харагдах вэ |
|---|---|
| UI гарчиг, чат, цэс | **«MGL AI 1.0»** — суурь загварын нэр ХЭЗЭЭ Ч биш |
| `/api/mgl-ai/session` → `model.release.base_model` | `Qwen3-4B-Instruct-2507` (админд оношилгоонд) |
| `ai_model_releases.base_model` / `base_model_license` | бүрэн метадата |
| **Энэ файл + `licenses/`** | лицензийн бүрэн текст |
| `docs/mgl-ai/ARCHITECTURE.md` | сонголтын шалтгаан |

Өөрөөр хэлбэл: **брэнд нь бидний, гарал үүсэл нь ил.** Apache-2.0 нь
брэндийн нэрийг заавал үзүүлэхийг ШААРДДАГГҮЙ (§6 нь эсрэгээр — барааны
тэмдгийн эрх олгодоггүй), тул энэ зохицуулалт нь лицензид бүрэн нийцнэ.

## 5. Хаалгыг нээх журам — БИЕЛЭГДСЭН

```
☑ 1. Лицензийн бүрэн текстийг хуулав  → registry/licenses/*.txt (sha256 бүртгэсэн)
☑ 2. Дөрвөн асуултад хариулав          → §2-ын хүснэгт
☐ 3. ai/registry/models.json → license_cleared: true      ← эзний батламжлалын дараа
☐ 4. D1: UPDATE ai_model_releases SET license_cleared = 1 ← релиз үүсгэх үед
☐ 5. ModelManager татна
```

⚠️ **3-4 дэх алхмыг ЭЗЭН батламжилсны дараа хийнэ.** Лицензийн ШИНЖИЛГЭЭ
хийгдсэн; ХУУЛЬ ЗҮЙН ХАРИУЦЛАГА нь компанийнх. Энэ файл нь баримтыг
бэлдсэн, шийдвэрийг биш.

## 6. Хөгжүүлэлт / үнэлгээний зам (түгээлт БИШ)

`MGLAI_MODEL_PATH` орчны хувьсагч нь **релизийн бүртгэлийг тойрч** гараар
авсан GGUF-ийг унших боломж өгнө.

⚠️ Энэ нь хаалгын цоорхой **БИШ**: лицензийн хаалга нь **түгээлтийг**
хаадаг (бид → 40 ажилтан), харин хөгжүүлэгч өөрийн машин дээр өөрөө
татсан жинг унших нь түгээлт биш. Ялгааг барихын тулд:

- энэ замаар ачаалсан загвар нь `model_version: 'dev-local'` гэж тэмдэглэгдэнэ
- `/info` нь `engine_reason`-д «ХӨГЖҮҮЛЭЛТИЙН ЗАГВАР» гэж ИЛ бичнэ
- `ai_model_releases`-д мөр ҮҮСГЭХГҮЙ, ажилтан руу ТАРАХГҮЙ
- `ai:benchmark` нь `dev-local` тоог продакшны тоо мэт харуулахгүй
