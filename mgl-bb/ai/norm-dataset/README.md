# ai/norm-dataset — Монголын барилгын нормын CANONICAL DATASET (L0–L4)

> Integrated 2026-09-16 from the proposed `highrise_ai_dataset_v1/` skeleton.  Every number in this
> file is **measured** (`npm run ai:norm:gate`, `npm run ai:eval:norm`); unmeasured numbers are not here.

## Юу вэ, юу БИШ вэ

Норм тус бүрийн **нэг эх сурвалжтай, дахин үүсгэгддэг** багц + **L0 бүртгэл** (аль норм байдаг, хүчинтэй юу,
аль баг/сэдэвт хамаарах, албан холбоос) + баталгаажуулах хаалга.  Энэ нь **сургалтын багц БИШ** — нормын
баримт нь ажилтны PC дээрх локал SQLite (`ai/knowledge`, `ai/retrieval`) руу шингэж, асуулт бүрд эшлэлтэй
татагдана; `training_ready/` нь зөвхөн **хянуулах** нэр дэвшигч (L4 бэлтгэл, QLoRA энд ажиллахгүй).

Одоо байгаа дэд бүтцийг **дахин бичээгүй**: 13 MCIS/MGL багц, `datasetProfiles.ts`-ийн 7 адаптер, `pipeline.ts`,
`norm-golden.mjs` бүгд хэвээр.  Нэмэгдсэн зүйл:

| Давхарга | Юу | Хаана |
|---|---|---|
| **L0 REGISTRY** | код · нэр · төлөв (MCIS бүртгэлээр) · баг/сэдэв · холбоос · орлуулга/төслийн граф | `registry/norms.jsonl` (ҮҮСГЭГДСЭН) ← `norms.seed.jsonl` + `mcis_verification.json` + `documents/*/metadata.json`; локал сангийн `ai_norm_registry*` хүснэгт; `ai/retrieval/src/registry.ts`; runtime `POST /norm/registry`, `/norm` → `registry` |
| **L1 DOCUMENT** | бүтэн бичвэр, хуудас бүрээр | `documents/<Doc>/parsed/document.md`, `pack/knowledge_chunks.jsonl` (FTS5) |
| **L2 CLAUSE** | заалт · хүснэгт · хавсралт · нэр томъёо · томьёо · тоон шаардлага · ишлэл — бүгд хуудас + URL-тай | `documents/<Doc>/parsed/*.jsonl` → `pack/` → `ai:ingest:norm` (`clause_document` профайл) |
| **L3 COMPUTE** | детерминист томьёо/хүснэгт | `backend/src/lib/mglai/norm` + `ai/norm-compiler` (БД 21-101-12-д бий; 31-17-10-д **хараахан алга** — доор) |
| **L4 BEHAVIOUR** | чиглүүлэлт, эшлэл, татгалзал, тооцооны хэрэгсэл | `training_ready/*.jsonl` (хянуулах нэр дэвшигч л) |

## Хоолой (норм бүрд ижил)

```bash
cd ai
python norm-dataset/tools/mcis_verify.py "31-17-10"                     # 0. MCIS бүртгэлээс төлөв/холбоос (нотолгоо)
npm run ai:norm:parse -- norm-dataset/documents/BNbD_31-17-10          # 1. PDF → parsed/   (pymupdf; Arial Mon хөрвүүлэлт)
npm run ai:norm:pack  -- norm-dataset/documents/BNbD_31-17-10          # 2. parsed/ → pack/
npm run ai:norm:registry                                               # 3. registry/norms.jsonl + references.jsonl
npm run ai:norm:gate  -- norm-dataset/documents/BNbD_31-17-10          # 4. GOLD хаалга (:memory: сан; --runtime URL --secret S нэмж болно)
npm run ai:ingest:norm -- norm-dataset/documents/BNbD_31-17-10/pack --strict   # 5. локал санд (өөр багцыг хөндөхгүй)
npm run ai:ingest:registry                                             # 6. L0 бүртгэл локал санд (идемпотент)
npm run ai:eval:norm                                                   # 7. бүтэн корпусын хэмжилт (регресс)
npm run ai:norm:training-ready                                         # 8. хянуулах SFT нэр дэвшигч (сургалт БИШ)
```

`ai:ingest:registry` нь схемийн хувилбар **өсгөхгүй** — `CREATE TABLE IF NOT EXISTS` тул одоо байгаа сан
хөндөгдөхгүй, шинэ хүснэгт л нэмэгдэнэ (`db.ts` DERIVED_TABLES-д орсон: дахин барихад хамт устна).

## Дүрэм

- **Төлөв таамаглагдахгүй.** `ACTIVE` зөвхөн MCIS-ийн бүртгэл «Хүчин төгөлдөр» гэсэн мөрөөс (`mcis_verification.json`);
  бусад нь `CANDIDATE_NEEDS_STATUS_CHECK`; төсөл `DRAFT`, `retrieval_default:false` — өгөгдмөл хайлтад гарахгүй.
- **Автоматаар задалсан текст = `official_pdf_text_layer_auto_extracted`** (`rules.ts` KNOWN_NON_EXECUTABLE).
  Хайгдана, эшлэгдэнэ; тоон шаардлага **эрх бүхий хариу болж гүйцэтгэгдэхгүй** — хүн хуудасны зурагтай тулгаж
  төлөвийг сольсны дараа л (`ingest.ts` `clause_document`: гүйцэтгэгдэх төлөвтэй мөр л дүрэм болно).
- **Ишлэл нь ишлэл.** Өөр нормын агуулгыг энэ багцад хуулахгүй — `references.jsonl` → `registry/references.jsonl`
  граф; дараагийн нормыг тэндээс сонгоно.
- **GOLD гэж хэлэхгүй** хүн баталгаажуулаагүй бол: хаалганы дүн `GOLD_CANDIDATE_PENDING_HUMAN_VERIFICATION`.
