# Багуудын хуудас — «Cockpit command-center» дизайн

**Огноо:** 2026-06-11
**Хамрах файл:** `frontend/src/features/teams/TeamsPage.tsx` (+ дэд компонентууд), `backend/src/routes/teams.ts`, i18n толь бичгүүд.

## 1. Зорилго

`/app/teams` хуудсыг одоогийн эрэмбэлэгддэг хүснэгтээс **«өнөөдрийн зураглал» command-center** болгон бүрэн солих. Гол асуулт: *аль баг өнөөдөр аль төсөл рүү чиглэв, нийт хүн хүч хаашаа хуваарилагдсан бэ*. Үүн дээр нэмж өмнөх өдрүүдийн зураглалыг ухраан харах боломжтой болгох.

Энэ хуудас удирдлагад (мөн бүх ажилтанд) "өнөөдөр хэн хаана ажиллаж байна"-г нэг харцаар өгөх ёстой.

## 2. Бус-зорилго (Non-goals)

- Ирц (attendance) модулийг шинээр бичихгүй — зөвхөн одоо хадгалагддаг `daily_active_projects` өгөгдлийг ашиглана.
- Хуримтлагдсан даалгавар/гүйцэтгэлийн түүхийг өдрөөр буцаан тооцохгүй (доорх §5-ыг үз).
- Багийн дэлгэрэнгүй хуудас (`TeamDetailPage.tsx`)-д өөрчлөлт оруулахгүй.
- Шинэ DB migration шаардлагагүй — өгөгдөл бэлэн.

## 3. Хэрэглэгчийн хандалт

- **Бүх ажилтан** command-center-ийг бүрэн харна (компани даяарын gol donut + бүх идэвхтэй багийн карт).
- **CRUD (баг нэмэх / засах / устгах / гишүүн нэмэх)** зөвхөн `admin` ба `senior`-т (`isAdmin` одоогийн логик хэвээр).
- Одоогийн `isScopedUser` шүүлтийг **устгана** — admin бус хэрэглэгч ч бүх багийг харна (зөвхөн унших).
- Clients нь `/client`-д sandbox хэвээр — энэ хуудас тэдэнд нээгдэхгүй (өөрчлөлтгүй).

## 4. Layout (Cockpit)

```
┌───────────────────────────────────────────────────────────────┐
│ eyebrow / Гарчиг / тайлбар      [‹ 📅 Өнөөдөр ›] [хайх] [+ Баг]  │
├──────────────┬───────────────────────────┬────────────────────┤
│  ЗҮҮН РЕЙЛ    │       ТӨВ HERO (алтан)     │   БАРУУН РЕЙЛ       │
│  баг карт     │   КОМПАНИ ДАЯАР · <огноо>   │   баг карт          │
│  баг карт     │     ◍ том gold donut       │   баг карт          │
│  баг карт     │   47 идэвхтэй хүн          │   баг карт          │
│  баг карт     │   [төсөл][баг][нийт хүн]   │   баг карт          │
│              │   Топ төсөл легенд         │                    │
├──────────────┴───────────────────────────┴────────────────────┤
│ ӨНӨӨДӨР ИДЭВХГҮЙ (3) › [EZ] [GT] [MGMT]                          │
└───────────────────────────────────────────────────────────────┘
```

- **3 баганат CSS grid** (`grid-template-columns: 1fr 1.15fr 1fr`).
- Идэвхтэй багуудыг (тухайн өдөр `active_projects.length > 0` эсвэл өнөөдрийн идэвхтэй хүнтэй) **хүний тоо/ачааллаар эрэмбэлж** зүүн-баруун хоёр баганд ээлжлэн (zigzag) хуваарилж тэнцвэржүүлнэ.
- Тухайн өдөр идэвхгүй (0 идэвхтэй хүн) багууд хоёр баганд **харагдахгүй** — доод footer дээр жижиг chip болж эвхэгдэнэ. Admin тэдгээр chip-ийг дарж засах боломжтой.

### 4.1 Багийн карт (`TeamCard`)

- Зүүн талд нарийн өнгөт зураас = **зонхилох төслийн өнгө** (gol donut-ийн зүсэмтэй тааруулсан). Идэвхгүй үед саарал.
- Код badge (`teamChipClass(team.code)`) + нэр (`pickLocalized` mn/en) + хүний тоо (`member_count`).
- **Өнөөдрийн төслийн split bar** — `active_projects[].percent`-ээр хуваасан өнгөт зураас (өнгө = `ACTIVE_PROJECT_COLORS` буюу төслийн id-д тогтвортой mapping, §6).
- Доор: зонхилох төслийн нэр + хүний тоо (`active_projects[0]`), 2+ төсөлтэй бол "+N баг/төсөл".
- `overdue_tasks > 0` бол улаан анхааруулга badge.
- **Hover (admin):** засах/устгах/гишүүн-нэмэх icon товчнууд гарна (одоогийн `TeamRow`-ийн үйлдлүүдтэй ижил, `e.stopPropagation()`-тэй).
- **Дарвал:** `navigate('/app/teams/:id')` — багийн дэлгэрэнгүй рүү (одоогийн `openTeam` хэвээр).
- **Hover нэмэлт interaction:** картыг hover хийхэд gol donut дээр тухайн багийн зонхилох төслийн зүсэм тодорно (доорх §4.3 highlight-state).

### 4.2 Төв hero (`CommandCenterHero`)

- Гарчиг: «КОМПАНИ ДАЯАР · <сонгосон огноо>».
- **Gold donut:** conic-gradient-ээр төслүүдийн өнөөдрийн идэвхтэй хүний хуваарилалт; гадна талд алтан цагираг (`box-shadow` ring + glow). Голд алтан тоо = нийт идэвхтэй хүн.
- 3 stat tile: идэвхтэй **төсөл** тоо, идэвхтэй **баг** тоо, **нийт хүн** (бүх багийн `member_count` нийлбэр).
- **Топ төсөл легенд:** хүний тоогоор эрэмбэлсэн дээд 3-4 төсөл (өнгө · нэр · хүн · %); үлдсэнийг «Бусад (N)» болгон нэгтгэнэ.
- **Нэмэлт (optional, v2):** легенд эсвэл зүсэм дээр дарахад тухайн төсөл рүү чиглэсэн багийн картууд тодорч бусад нь бүдгэрнэ ("color-link" interaction).

### 4.3 Highlight state

- `hoveredTeamId` / `selectedProjectId` зэрэг local state-ээр карт ↔ donut хоорондын харилцан тодролыг удирдана. Хоосон үед бүгд хэвийн.

## 5. Огноо-аялал (time-travel)

- Толгойд **огноо-навигатор**: `‹` (өмнөх өдөр), огноо-шошго (`📅 YYYY-MM-DD · <гариг эсвэл "Өнөөдөр">`), `›` (дараах өдөр — өнөөдөр дээр идэвхгүй/бүдэг, ирээдүй рүү явахгүй).
- Өнгөрсөн огноонд байгаа бол «Өнөөдөр рүү буцах» товч/линк нэмж харагдана.
- Сонгосон огноо `?date=YYYY-MM-DD` болж `GET /teams`-д очно; default = `todayInUB()`.
- **Хамрах хүрээ:** огноо нь зөвхөн **өдрийн идэвх** датаг шилжүүлнэ — `active_projects`, `active_project_count`, gol donut, картын split bar, идэвхтэй баг/хүний тоо. Эдгээр нь `daily_active_projects.date`-аас гардаг.
- **Хуримтлагдсан** статистик (`total_tasks`, `completed_tasks`, `overdue_tasks`, `avg_progress`) нь огноогоор буцдаггүй тул одоогийн утгаараа үлдэнэ. UI-д энэ ялгааг ойлгомжтой байлгана (хуримтлагдсан тоонуудыг картын гол фокусаас гадуур, эсвэл өнгөрсөн огноо үед бүдэгрүүлэх).
- Тухайн өдөр идэвхтэй баг байхгүй бол хоёр рейл хоосон → зөөлөн мессеж: «Энэ өдөр идэвхтэй баг бүртгэгдээгүй». Хуудас унахгүй.

## 6. Төслийн өнгөний тогтвортой mapping

`ActiveProjectPie`-д одоо өнгийг **индексээр** (массив дахь дараалал) сонгодог тул карт болон gol donut дээр нэг төсөл өөр өнгөтэй болж магадгүй. Command-center-т **«аль баг аль төсөл рүү»**-г өнгөөр уншуулах тул нэг төсөл = нэг өнгө байх ёстой.

- Тухайн өдрийн бүх `active_projects`-ийг нэгтгэж, хүний тоогоор эрэмбэлсэн дараах **төсөл→өнгө** map үүсгэнэ (`ACTIVE_PROJECT_COLORS` тойрог). Дээд N-ээс хэтэрсэн төслүүд «Бусад» өнгөнд орно.
- Энэ map-ийг hero, картын split bar, зүүн өнгөт зураас бүгдэд нэг эх сурвалжаас дамжуулна.

## 7. Backend өөрчлөлт (`backend/src/routes/teams.ts`)

`GET /api/teams` дотор:

1. `const today = todayInUB();` мөрийн оронд query param-аас огноо авна:
   ```ts
   const dateParam = c.req.query('date');
   const isValid = dateParam && /^\d{4}-\d{2}-\d{2}$/.test(dateParam);
   const today = todayInUB();
   // ирээдүй рүү явуулахгүй: today-оос их огноог today болгож хязгаарлана
   const date = isValid && dateParam <= today ? dateParam : today;
   ```
2. `.bind(today, today)` → `.bind(date, date)` (хоёр `dap.date = ?` байрлал).
3. Бусад CTE, бүтэц, буцаах форм өөрчлөгдөхгүй — нэмэлт талбар нэмэхгүй.
4. (Сонголт) Хариунд `date` талбарыг буцааж UI баталгаажуулахад ашиглаж болно.

## 8. Frontend бүтэц

`TeamsPage.tsx`-ийг доорх фокустай дэд компонент болгон задлана (нэг файл томрохоос сэргийлж):

- `TeamsPage.tsx` — өгөгдөл татах (`useApiQuery('/teams', { date })`), огноо/highlight state, layout композици, CRUD dialog-ууд (одоогийнхтэй ижил).
- `components/DateNavigator.tsx` — огноо сонгогч (‹ / огноо / ›, «Өнөөдөр рүү буцах»).
- `components/CommandCenterHero.tsx` — gol gold donut + stat tile + легенд.
- `components/TeamCard.tsx` — багийн карт (split bar, hover үйлдэл).
- `lib/projectColors.ts` — өдрийн `active_projects`-аас төсөл→өнгө map үүсгэх цэвэр функц + нэгтгэх/эрэмбэлэх туслахууд.
- CRUD dialog-ууд (`create/edit`, `delete`) болон `progressTone/progressBar` туслахууд хэвээр шилжинэ.

`useApiQuery`-д `date` өөрчлөгдөхөд дахин татахын тулд query key-д `date`-ийг оруулна.

## 9. Responsive

- `lg+`: 3 баган.
- `md`: hero дээр, дараа нь багууд 2 баганд.
- `sm` (мобайл): hero дээр, багууд 1 баганд босоо стек. Footer chip-үүд wrap хийнэ. Одоогийн мобайл картын стек логикийг ашиглаж болно.

## 10. i18n

Шинэ мөрүүдийг `frontend/src/i18n/en.json` ба `mn.json` **хоёуланд** нэмнэ. Жишээ key-үүд: `teams.todayLabel`, `teams.companyWide`, `teams.activePeople`, `teams.activeTeams`, `teams.topProjects`, `teams.others`, `teams.inactiveToday`, `teams.backToToday`, `teams.noActiveTeams`, `teams.dominantProject`. Одоогийн `teams.*` key-үүдийг дахин ашиглана.

## 11. Эрсдэл / анхаарах

- **Хуримтлагдсан vs өдрийн дата холилдох** — UI-д тодорхой ялгах (§5).
- **Олон багтай тэнцвэр** — идэвхтэй баг сондгой тоотой үед нэг баган 1-ээр илүү байж болно (зүүн талд илүү).
- **Хоосон/амралтын өдөр** — зөөлөн мессеж, алдаа биш.
- **Backend deploy** — manual (CI эвдэрхий; memory: [[backend-deploy-ci-status]]). Энэ өөрчлөлт зөвхөн нэг route-д хийгдэх тул эрсдэл бага.
- **Frontend deploy** — `dist/` гар аргаар Pages-д (memory: [[frontend-deploy-preference]]).

## 12. Хийх дараалал (өндөр түвшний)

3. `TeamCard`, `CommandCenterHero`, `DateNavigator` компонентууд.

6. Responsive тааруулах.
7. (Сонголт) color-link highlight interaction.
