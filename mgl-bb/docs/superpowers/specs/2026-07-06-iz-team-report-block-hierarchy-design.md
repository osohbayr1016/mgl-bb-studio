## Асуудал

Багийн тайлангийн «ЯВЦЫН ТОЙМ» хүснэгт (`frontend/src/features/projects/team-reports/TeamComponentStatsPanel.tsx`) одоогоор иерархийг **хавтгайруулдаг**: ижил нэртэй бүрдлүүдийг бүх блок/зургаас нэгтгэж, блокийн гарчиг огт харагддаггүй. Интерьер (ИЗ) багийн хувьд блокууд нь давхар/бүсээ илэрхийлдэг тул энэ нэгтгэл мэдээллийг алддаг — хэрэглэгч тайланг **Блок → Зураг → Бүрдэл → Ажил** гэсэн бүрэн задаргаатай харахыг хүссэн (зөвхөн ИЗ багт; бусад багийн тайлан хавтгай хэвээр).

## Шийдэл (сонгосон хувилбар)

Панел дотроо багийн кодоор салбарладаг болгоно: `HIERARCHICAL_TEAMS = new Set(['IZ'])` тогтмол; жагсаалтад орсон багт `buildRows`-ын оронд блок задаргаат мод бүтээдэг `buildBlockRows` ажиллана. Панел 3 газар (дэлгэцийн «Тайлан» горим, багийн print/PDF хуудас, гүйцэтгэлийн тайлангийн PDF) ашиглагддаг тул нэг дороос гурвуулаа ижил харагдана.

Хэрэгсээгүй хувилбарууд: (а) call site бүрт `layout` prop дамжуулах — 3+ газар зэрэг засах, зөрөх эрсдэлтэй; (б) тусдаа `IzBlockStatsPanel` — стиль/логик давхардана.

## Нарийвчилсан загвар

**Мод бүтээх (`buildBlockRows`):**
- `data.blocks.filter(b => b.team_id === teamId)` — одоогийнхтой ижил шүүлт.
- Мөр бүрийн **Биелэлт** нь серверийн тооцсон `progress` талбар (block/drawing/component), ажлын мөр `task.progress`. (Хавтгай горим нэрээр нэгтгэдэг учраас л дундажийг дахин тооцдог байсан; модонд серверийн канон утга шууд хэрэглэнэ.)
- **Жин** багана нь түвшин бүрд «багийн нийт ажлын хувь» байхаар нормчилно: блокийн жингүүд 100 болтол нормчлогдоно; зураг = блокийн жин × блок доторх нормчилсон жин; бүрдэл, ажил мөн адил. Ингэснээр түвшин бүрийн нийлбэр 100 гарна. Жин бүгд 0 үед тэнцүү хуваах fallback (одоогийн хавтгай горимын философи хэвээр).
- Хоосон блок/зураг мөрүүдийг **нуухгүй** — нуувал Жин багана 100 болж нийлэхгүй, худал уншигдана.

**Рендэр:**
- Ижил нэг хүснэгт; задаргаат горимд эхний баганын толгой «Блок / Зураг / Бүрдэл / Ажил».
- Шинэ мөрийн ангиуд: `team-stats-doc__row--block` (navy #1B3A5F дэвсгэр, цагаан текст — thead-ийн #0F243E-ээс арай цайвар, эс бөгөөс эхний блок толгойтой нийлж уншигддаг; цагаан туяат хүрээ нь зэрэгцсэн хоосон блокуудын заагийг ялгана), `--drawing` (цайвар туяа), бүрдэл/ажил одоогийн стилээ хэрэглэнэ.
- Догол мөр зөвхөн задаргаат горимд үйлчилнэ (`team-stats-doc__table--tree` scope): блок 0 / зураг 14px / бүрдэл 28px / ажил 44px. Хавтгай горимын харагдац өөрчлөгдөхгүй.
- `@media print`: блок мөрөнд `break-after: avoid-page`, шинэ өнгөт мөрүүдэд `print-color-adjust: exact`. Шинэ print дүрмүүд бүгд `--block`/`--drawing` ангиар scope-логдоно — flat горимын гар хэвлэлт (`window.print()`, Background graphics off) битээр өөрчлөгдөхгүй.

**Өөрчлөгдөх файл:** зөвхөн `frontend/src/features/projects/team-reports/TeamComponentStatsPanel.tsx`. Backend, i18n, роут өөрчлөгдөхгүй.
